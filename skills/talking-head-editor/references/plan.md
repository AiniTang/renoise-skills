# 逐句剪辑方案

剪辑方案决定成片质量的八成。粗剪之后、动手渲染之前，把每一句话该怎么处理想清楚，写成 `plan.md` 给用户看，确认后再翻译成 `timeline.json`。

## 第一步：先看全片，分段落

先按结构切段，再逐句包装（script_segment_plan）：同一段共享一套包装和配乐，逐句做之前先定好段落，后面每句才不会各做各的。

1. 通读 lines.json，把全片分成 3 到 8 个段落（开场 / 第一点 / 第二点 / … / 结束语，或开头钩子、背景、要点、转折、行动号召），每段起一个小标题，写清起止时间和情绪（舒缓、信息密、欢快、提气），给一句包装建议。3 段以上或 3 分钟以上的口播必须做，rhythm_check 会查。
2. 标出全片的情绪曲线：哪里在铺垫、哪里是高点、哪里抖包袱、哪里是结论。高点和结论是重点包装的位置，铺垫段保持克制。
3. 估算 B-roll 占比目标：
   - 高级感信息卡片式（知识、财经、科普）：B-roll 占 50%~65%，口播全屏约 30%；
   - 高级感人物大字报式（观点、方法论）：B-roll 占 20%~40%，靠大字和构图撑；
   - 综艺感：B-roll 占 30%~50%，口播全屏多，情绪包装密。

## 第二步：逐句定五件事

| 要定的事 | 选项 | 怎么判断 |
|---|---|---|
| 字幕等级 | 口播底字 / 重点句 / 框架概要 / 关键词 | 观众看完这条视频必须记住的才升级。重点句约占 10%~20%，关键词每 10~20 秒最多一个 |
| 版式 | 口播全屏 / 人物移出（aside）/ 圆形小窗（pip）/ 全屏素材（hidden） | 讲观点、讲情绪、讲自己的经历留全屏；讲具体东西（截图、数据、产品、操作）切走 |
| B-roll | 无 / 用户素材 / 代码图形 / 素材库 / Renoise 生成 | 见下面「句子类型 → 画面」对照表 |
| 包装 | 推近、大字、卡片、局部放大、定格、转场 | 见对应风格文件和 `recipes.md` |
| 声音 | 对着内容的音效、配乐变化、留白 | 画面里有动作（打字、数字滚动、清空、出错、上涨下跌）或口播说到关键词时，从声音清单里挑一个对得上的，写进 sound / sounds；其余交给自动配。见 `audio.md`「音效怎么配」 |

### 句子类型 → 画面

| 这句话在说什么 | 画面怎么给 | 例子 |
|---|---|---|
| 一个具体数字、金额、比例 | 代码图形：数字滚动或柱状图 | 「估值 1.5 万亿美元」→ number 模板 |
| 两样东西的对比 | 代码图形：左右对比卡，或两张截图分屏 | 「Claude 规划强，Codex 写代码快」→ compare 模板 |
| 几个步骤或清单 | 代码图形：步骤清单逐条出现 | 「三步：初始化、存档、回退」→ steps 模板 |
| 一段历史或发展过程 | 代码图形：时间轴 | 「2015 年第一次回收…」→ timeline 模板 |
| 引用一句原话、金句 | 金句卡或大字 + 底板 | 「不能依靠 AI 的记忆来撤回」→ quote 模板 |
| 说到某个产品、网页、聊天记录、报告 | 用户截图做卡片（aside），没有就请用户补或用浏览器截一张 | 「我把扫描件丢给 AI」→ 截图卡片 |
| 演示操作过程 | 用户录屏铺满 + 圆形小窗（pip），等待段加速 | 「它自己开始用浏览器测试了」 |
| 新闻、事件、公告 | 新闻截图卡片，标出关键句（荧光笔效果） | 「星巴克发公告说…」 |
| 一个具体的场景或物体 | 素材库搜空镜；搜不到用 Renoise 生成 | 「火箭发射」「深夜加班的办公室」 |
| 一个抽象概念或比喻 | Renoise 生成概念画面，或干脆留口播全屏用大字 | 「天地一张网」 |
| 自己的情绪、态度、吐槽 | 口播全屏，推近；综艺感加情绪包装 | 「我真的吓出冷汗」 |
| 开场钩子 | 先给结果画面（成品、结论数字）或抛问题大字，3 秒内 | 「AI 帮我办的澳洲签证刚刚下签了」 |

### 大字和关键词怎么摆

- **永远别压在脸上**。竖屏人像的脸一般在 y=0.25~0.45 之间，大字放头顶上方（y=0.10~0.20）、身体两侧（x=0.2 或 0.8，y=0.30~0.55）或画面下半部分（y=0.55~0.70，字幕上方）。
- 两侧摆放时字要短（2~4 个字），一侧一个词。
- 关键词大字出现时，同一时刻的普通字幕可以保留（它在胸口位置），但不要再叠第三层文字。
- 画面上同一时刻最多一个视觉焦点：大字、卡片、小窗三选一为主。

### 节奏的几个硬数字

- 跟读字幕每屏 7~12 字，每秒约 6.5~7.5 字。
- B-roll 单个画面停留 1.5~4 秒；超过 4 秒要有运动（缓推、上升、局部放大）或换下一张。
- 同一种包装连续出现不超过 3 次，否则观众会麻木。
- 口播全屏连续超过 8 秒，就该插一次推近、一个大字或一个 B-roll。
- 开头 10 秒决定观众留不留，每 2 秒内至少换一次画面，跟着口播的词走：痛点词大字、说到工具时身后换成工具画面、对比词放人两侧、说到数字就滚数字、说「这几个」就弹目录。rhythm_check 会逐段查。

## 第三步：写 plan.md 给用户看

用大白话，先放段落表，再按段落分组逐句写，每句一行。不要出现 timeline.json 里的字段名。

```markdown
## 段落

| 段落 | 时间 | 情绪 | 包装和配乐 |
|---|---|---|---|
| 开场钩子 | 0:00-0:08 | 提气 | 照片快速叠入、大字砸下；开头一段激昂鼓点，7 秒处接主配乐 |
| 第一点 版本管理 | 0:08-0:31 | 舒缓 | 章节页 + 截图卡片；主配乐压低 |
| 第二点 会话太长 | 0:31-0:52 | 信息密 | 录屏快剪；换一首快一点的，嗖一声换过去 |
| 结束语 | 0:52-1:01 | 舒缓 | 回到口播全屏，关注尾帧；配乐留白一秒再收尾 |

## 第 1 段：开场钩子（0:00-0:08）

| 时间 | 说的话 | 画面 | 字幕 | 声音 |
|---|---|---|---|---|
| 0:00 | Vibe coding 一年半以来 | 4 张自己写代码的照片快速叠入 | 普通字幕；大字「一年半」放头顶 | 开场一声低音鼓 |
| 0:02 | 我踩了无数的坑 | 口播全屏，快速推近 | 「踩坑」大字放左侧 | — |
| 0:04 | 今天分享下新手都会踩的 6 个坑 | 口播全屏 | 「6 个坑」重点句放大变黄 | 轻「叮」 |
| 0:06 | 最后那个直接导致我的文件夹被清空 | 文件夹被清空的录屏，人缩成右下角圆形小窗 | 普通字幕 | 配乐从这里起 |

需要你确认或补充的：
- 第 0:06 句的录屏我用的是你给的 A0-folder-clear.mov；
- 第 2 段的「火箭发射」空镜，素材库搜不到合适竖屏的，建议用 Renoise 生成 2 段（Wan 3.0，约 X 积分）。
```

方案末尾列出：要用户补的素材、要花积分的生成项和报价、发现的敏感信息。

## 第四步：翻译成 timeline.json

- 跟读字幕用 `init_timeline.py` 自动生成，再按方案改 `level`、`hl`。
- 段落表写进顶层 `sections`（起点、段名、情绪），配乐换曲、留白、声音先入都按它走；用户给了几首曲子写进 `audio.tracks` 并标情绪。
- 版式写 `layout`，画面写 `broll`，推近写 `zoom`，声音写 `audio`。
- 跟着内容走的关键词大字写 `beats`：方案表里每句的「包装」列已经写了这句是并列、对比、数字还是金句，直接翻成 beat 和要上屏的字，手法和变体由代码从手法库挑（见 `library.md`）；章节页、角标、片尾这类固定版式的大字写 `titles`。
- 时间对齐原则：B-roll 和版式切换对齐到某一句话的开头（lines.json 里的 t0），不要切在一句话中间；推近对齐到字幕切换点。
- 先 `render.py --preview` 出低清预览，用 `contact_sheet.py` 拼图自查，再出正式成片。

## 完整示例：财经知识片段（高级感、信息卡片式）

口播原文（粗剪后）：
> 前几天马斯克的 SpaceX 公布了上市计划，目标估值 1.5 万亿美元，很可能成为史上最大的 IPO。火箭可以说是 AI 和机器人之后，又一个全球争霸的赛道。25 年全球一共发射了 300 多次，中国占了四分之一。

| 句子 | 方案 |
|---|---|
| 前几天马斯克的 SpaceX 公布了上市计划 | 新闻截图卡片（aside），卡片缓慢上升；「上市计划」用荧光笔划出 |
| 目标估值 1.5 万亿美元 | 数字滚动图形（hidden 全屏素材 + 代码图形），配一声重音鼓，配乐随鼓点收住，留白 0.3 秒 |
| 很可能成为史上最大的 IPO | 回口播全屏，快速推近；「史上最大」重点句 |
| 火箭可以说是 AI 和机器人之后，又一个全球争霸的赛道 | 火箭发射空镜（素材库或 Renoise 生成），人缩成右上角圆形头像（pip）；大字「全球争霸」配英文副标 |
| 25 年全球一共发射了 300 多次，中国占了四分之一 | 柱状图图形（中国那一条用强调色），继续 pip |

对应的 timeline.json 片段：

  {"t0": 2.6, "t1": 4.9, "src": "broll/valuation.mov", "fit": "contain", "w": 0.9, "y": 0.45, "enter": "fade"},
