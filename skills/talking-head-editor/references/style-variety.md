# 综艺感包装

热闹、密集、情绪起伏大。核心是**每个情绪点都给反馈**：说到疑问有问号，说到翻车有打击，说到灵感有灯泡，配合音效让观众「被逗到」。综艺感的大部分手段是剪映自带素材（人脸特效、花字、综艺文字模板、音效库），**推荐导出剪映草稿**；纯代码成片用表情图、大字和音效近似。

## 字幕与花字

- 跟读字幕：抖音美好体白字 + 细黑边，胸口位置，有小窗时上移。
- 重点句：整句或关键词换成彩色花字（剪映「黄色条纹花字」最常用），字号放大一档，入场动画（弹入、呐喊声波、生长、滚入、弹簧），同时配一声「啵」或「叮」。约 10%~30% 的字幕做成重点句。
- 只放大关键词：一句里只有关键词换花字加大，其余白字小号，比如「怒省**800 多**块中介服务费」。
- 双词对比弹出：两个关键词一左一右先后弹出（「有趣」「有用」），各配一声「啵」。
- 连续列举：三个并列词连续三屏，每屏一个，花字 + 三连「啵」。
- 章节标题卡：「第一、……」整句放画面上方，圆角色块垫底，逐字出现，人物抠像放下方。

timeline 写法：`subs` 的 `level: key` + `hl` + `jy_flower: "黄色条纹花字"`；大字用 `titles`。可用的花字名见 `assets/jianying_resources.json`。

## 人脸特效与画面特效（剪映）

写在 timeline 的 `effects`，只在剪映草稿生效。贴在情绪点上 0.6~3 秒，常两个叠用。

| 情绪点 | 人物特效 | 画面特效 |
|---|---|---|
| 疑问、懵 | 一脸问号、懵、大头 | — |
| 吃惊 | 惊讶、大头 | 聚光灯 |
| 吐槽、无语 | 真的会谢、宕机中、尴尬住了 | — |
| 翻车、被打击 | 打击、中刀、难过、石化了、灵魂出走 | 裂开了、震动 |
| 想到办法 | 灵机一动 | — |
| 戏剧性强调 | — | 聚光灯 + 荧幕噪点 + 暗角 |
| 念别人原话 | 真的会谢 | 录制边框 III + 胶片框 |
| 指出重点 | — | 放大镜 |
| 失落 | 难过 | 变黑白 |
| 片尾 | — | 全剧终 |

纯代码成片的替代：在 `overlays` 放对应的表情图（问号、灯泡、汗滴），或 `titles` 放短词（「？？？」「啊这」）配音效。

## 贴纸

少而精，每期 1~8 个：互动引导（收藏、点赞关注）、标注（红框、叉、箭头、数字）、情绪（问号脸、灯泡、星星）、划重点。写在 `stickers`（剪映）或 `overlays`（代码）。

## 音效对照表

每分钟 10~30 个，这是综艺感的主要来源。剪映草稿可以用用户剪映收藏里的音效；分享给别人的版本用 Mixkit 等免版权音效库（`scripts/music_search.py sfx <类别>`）。

| 画面事件 | 音效 |
|---|---|
| 花字、关键词出现 | 叮、Pling、叮咚 |
| 图片、文字冒出 | 啵、弹出声 |
| 截图翻入、画面切换 | 翻书声、唰、嗖 |
| 开场第一秒 | 低沉的「咚」、叮叮叮 |
| 疑问 | 疑问「嗯？」、问号音效 |
| 想到办法 | 灵感「叮」 |
| 吐槽、翻车 | 拳击声、重物落地、重音、咣当、心碎 |
| 成功、做到了 | 任务完成、答题正确、金币声 |
| 操作演示 | 鼠标点击、键盘打字 |
| 屏蔽不能说的词 | 哔声消音 |
| 片尾署名 | 收银机「叮」 |

音量：-12 到 -4 dB，比人声小但听得清。

## 组合配方

| 配方 | 组成 |
|---|---|
| 重点句 | 花字、字号放大、入场动画、叮或啵、快速推近 |
| 抛问题 | 花字、呐喊声波动画、一脸问号、疑问音效 |
| 戏剧聚焦 | 聚光灯、荧幕噪点、暗角、重音、红色裂痕花字 |
| 吐槽翻车 | 真的会谢或打击、拳击声或重物落地 |
| 灵光一闪 | 灵机一动、灵感叮、灯泡贴纸 |
| 念原话 | 扩音器变声（剪映音频效果）、录制边框、胶片框 |
| 内心独白 | 原声静音、文本朗读角色音加速 1.3~1.8 倍、人脸特效 |
| 开场快闪 | 4~5 张照片或 logo 每张 0.2~0.5 秒叠入、随机微旋转 ±10 度、每张一声「唰」、标题花字 |
| 片尾 | 账号署名放大滚入、收银机叮、点赞关注收藏贴纸 |

## 节奏

- 平均两秒一刀，重点句开口必推近。
- 口播全屏超过 5 秒就该有一个情绪包装或画面变化。
- 同一个音效连续用不超过 3 次，换着用。

## 不要做

- 每句都上特效：情绪点之间要有安静的铺垫，否则观众累。
- 音效盖过人声。
- 在高级感视频里用这一套。
