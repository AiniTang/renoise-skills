# 动效层：把动态设计功力融进每一支片

宣传片的「内容层」（官网素材、真实界面、卖点、数据）决定说什么，「动效层」决定观众怎么看见它。

**素材优先，动效长在产品上。** 先铺官网截图、产品界面、Logo、头像、成品图。粒子、单形状、方块阵都可以用，但必须叠在这些素材上：粒子在稻田截图上聚成口号，圆形擦除从点击处打开真实路面，同一条街白天切成祭典夜。不要单独切一段黑底粒子或通用 UI。用户只要「秀动效」时才走 `examples/motion-reel/`。

内容层按 cinematic.md 搭好后，再按本文加一遍动效层：每段挑一个主手艺，段与段之间设计转场，全片首尾呼应。组件都在 `src/cinematic/MotionKit.tsx`、`ParticleText.tsx`、`CubeField.tsx`。动效层融入产品片的完整示例见 `examples/youware/`。

## 1. 两个档位

同一套手艺，按风格选档位，一支片只用一个档位（下表三档）：

| 档位 | 适用 | 手艺强度 | 允许 |
|---|---|---|---|
| 克制（默认） | 暗场科技、浅色编辑、温馨暖色、Apple 式回顾 | 每段一个手艺，动作到位即停；转场以匹配剪辑、遮罩上滑、轮播推移为主 | 品牌自己在用的渐变字，只给一个关键词；HUD、颗粒只在科技风里用，且透明度更低 |
| 表现 | 社媒广告、发布会开场、频道 ID、动效作品集、年轻消费品牌 | 每拍都有动作，底色按拍翻转，字体动画跟着词义走 | 满屏高饱和强调色、胶片颗粒、HUD、圆形擦除、竖条遮罩、粒子炸开 |
| 精密 UI | 界面动效循环片、产品 UI 细节展示、Dribbble 风格 | 一个形状不切镜头，弹簧驱动，光标真实点击拖拽，每拍一个变化 | 只有暖灰画布、黑白组件和至多一个强调色；禁用夸张回弹、粒子、辉光、渐变（见 one-shape.md） |

design-principles.md 的「克制用色」「装饰透明度 ≤ 0.2」只约束克制档；表现档照样要求每帧只有一个焦点、切点落在节拍上。

## 2. 手艺地图：片中哪个位置用什么

| 片中位置 | 手艺 | 组件 | 要点 |
|---|---|---|---|
| 冷开场 0–4 秒 | 物理弹跳 + 挤压拉伸，或品牌物件飞入点击 | 自写（参考 motion-reel `Intro`）| 小物体落地弹 2–3 下，每次触地压扁，第三下变形成线、光标或 Logo 的一部分；声音一次比一次轻 |
| 口号揭示 | 字母从基线升起 | `KineticWord variant="rise"` | 基线就是上一镜拉出的那条线，形成匹配剪辑 |
| 卖点标题 | 词义匹配的字体动画 | `KineticWord`：`step` 讲速度/效率，`elastic` 讲灵活/顺滑，`wave` 讲节奏/协作，`strips` 讲组合/集成 | 每个卖点只选一种，同一支片里不重复 |
| 卖点之间 | 圆形遮罩揭示下一段，或竖条遮罩换页，或圆形擦除换底色 | `IrisReveal`、`SlatReveal`、`CircleWipe` | 揭示圆心放在上一镜的焦点（刚交付的提示条、手机、表盘中心）；两段 Sequence 重叠 `dur` 帧、下一段在上层；竖条每条错开 0.6 帧，9 帧内必须归位 |
| 功能图标、模式切换 | 形状变形 | `ShapeMorph`、`morphPath`、`SHAPES` | 圆 → 方 → 六边形这类几何变形比淡入淡出更有设计感；Logo 是几何形时，用变形收进 Logo |
| 规模、数据、算力 | 3D 实例阵列 | `CubeField` | 讲「很多」「一直在跑」时用；曝光约 0.7、辉光 0.45，否则发白 |
| 高潮口号 | 粒子汇聚成字再炸开 | `ParticleText text size colors count background` | 全片最多一次，放在收尾前一段；颜色用品牌色；中文口号 11 字左右用 `size≈148`、`count≈8000`，字要离画面左右边缘 ≥ 60 px；炸开的一帧（第 60 帧）配 `impact` |
| 功能清单、快节奏 | 竖条遮罩逐拍换词 | `SlatReveal` + 大字 | 一拍一个词，4 个以内 |
| 科技感质地 | HUD、胶片颗粒 | `Hud`、`FilmGrain` | 克制档颗粒 ≤ 0.05，HUD 只留角标和时间码 |
| 关键拍强调 | 只有 Logo 落地、章节翻转、高潮这几拍镜头推一下 | `AudioProvider`、`HitCam`、`ReactiveType`、`Spectrum`（见 style-pack-01.md） | 先跑 `audio_features.py`；每支片 3–5 个关键帧，其余机位锁定；**不要整段包 `BeatCam` / `KickFlash`** |
| 「多合一」卖点、段落转场 | 液态融合、液态擦除 | `Goo` + `morphBlobs`、`LiquidText`、`LiquidWipe` | 精密 UI 段别用；字最后必须清晰 |
| 增长、对比、占比 | 排名赛跑、趋势线、占比环 | `BarRace`、`LineReveal`、`DonutBuild` | 只用真实数据，否则标「演示数据」 |
| 开场、模型墙、作品集 | 一镜到底穿过多个画面 | `InfiniteZoom` | 每张图都要有可钻入的物体 |
| 结构、参数、技术卖点 | 光标透视揭示内部 | `XRayReveal` + `Blueprint` | 两层像素对齐，标注写真实参数 |
| 收尾 | 首尾呼应 | 开场那个物件回来，变形成 Logo 下划线或 CTA 按钮 | 让观众感到「一镜到底」 |

## 3. 用户说「不够 dynamic / 不够炫」时

这通常意味着片子停在克制档：卡片淡入、遮罩上滑、镜头不动。按下面逐项加码，内容和分镜不用改：

1. **镜头动起来**：每段包一层 `Stage`（持续微倾 + 推进），段间用 `whipIn / whipOut` 甩镜，外面包 `CameraMotionBlur`（粒子、3D 段除外）。
2. **字动起来**：标题全部换成 `KineticHeadline`（逐字 rise / elastic / slam，中文可用），同一支片三种轮换。
3. **关键拍震一下**：只在 3–5 个关键帧（Logo 落地、章节翻转、高潮）用 `HitCam` 推镜。不要在根节点做 `beatPulse` 全片跟拍——整片一直在震，观众感觉是背景在抖（用户明确反馈过）。
4. **开场改成痛点快切**：一拍一个痛点词，`CircleWipe` 翻底色，最后一个词缩成点，匹配剪辑成 Logo。
5. **把「过程」做成动作**：比如剪刀沿声波逐个剪掉气口、光点顺着连线流进目标、指针飞转后结果随闪光砸出。每个动作都配音效。
6. **列表逐拍砸入**：标签用 1.7→1 缩放加模糊砸入，外加一圈渐隐光晕；卡片墙改成持续旋转的 3D 轮播；背景放巨大的描边编号。
7. **加高潮**：收尾前 2.5 秒用 `ParticleText` 汇聚口号再炸开，炸开中心对准收尾 Logo。

运动模糊让渲染慢约 3–5 倍，先用样帧确认，再整片渲染。

## 4. 转场设计

先在分镜表加一列「转场」，每个段落接缝写清楚是哪一种，全片至少三种、硬切不超过一半：

- **匹配剪辑**：上一镜的形状、位置或运动方向延续到下一镜，比如小球拉成线、线变成下划线、形状缩成点、点变成光标、Logo 飞进截图里它原本的位置。优先用。
- **遮罩类**：圆形擦除从焦点扩散，竖条遮罩交错滑动，文字遮罩上滑。
- **镜头类**：穿越 Logo、猛推、甩镜，见 design-principles.md「导演运镜」。
- **轮播推移**：多作品、多卡片时整排推一格（见 recap.md）。
- **明暗转折（熄灯）**：明→暗最容易变成硬切。灯光约 1 秒渐暗，一个承载物（句点、光点、Logo 的一部分）保持发亮并点燃光晕，全黑之后才卸载旧场景，新内容径向从承载物里长出来；声音同步关灯、尾音、渐入（detail-pass.md「连续性配方」）。
- **硬切**要有意：落在节拍或动作上，写在分镜的转场列；`rn cuts --sheet` 会把成片里所有硬切列出来、附每刀前后帧，逐个确认。

## 5. 实现规则

- 所有动效由帧号算出；弹性缓动用 `ELASTIC`，其余用 `motion.ts` 的 `E`。
- 纯 DOM/SVG 段落的快速动作包 `<CameraMotionBlur shutterAngle={200} samples={6}>`；3D、Canvas、视频段落不包（慢且没必要）。
- 粒子用 2D Canvas、位置按帧号解析计算，不累积状态；少于约 6000 个时大字发虚。
- 形状变形用极坐标半径函数，任意两形状都取同样 240 个点插值。
- 表现档调色：墨黑 + 米白 + 至多三种高饱和强调色；做品牌片时把强调色换成品牌色，别硬套示例配色。

## 6. 动效作品集（纯秀手艺）

用户只要「展示动效能力」时，按 `examples/motion-reel/` 的 15 秒结构：弹跳 → 动态字 → 变形 → 3D → 粒子 → 竖条节奏 → 首尾呼应，每 2–2.5 秒一种手艺，每段结尾元素变成下一段开头；叠 `Hud` 与 `FilmGrain`；音效卡在每个物理接触点上。
