# 运镜

本文是模板片（`Promo`）的运镜参数。电影级 Film 的导演镜头语言（推轨、焦点转移、甩镜、穿越、猛推）见 [design-principles.md](design-principles.md)「导演运镜」。

动效视频里的「镜头」是虚拟的：`Camera` 组件对整个场景做变换，`Layer depth` 让背景（depth 0.25–0.6）比主体（depth 1）移动得少，从而产生视差纵深。每个场景的 `camera` 字段选择一种运动，不填则用风格默认值。

## 可用运镜

| 值 | 效果 | 经典出处 / 用途 |
|----|------|-----------------|
| `push-in` | 缓慢推近 | 肯·伯恩斯效果；强调、引出结论，最通用 |
| `pull-out` | 缓慢拉远 | 揭示全貌；片尾品牌露出 |
| `pan-left` / `pan-right` | 横移 | 并列信息（功能卡片）时引导视线方向 |
| `tilt-up` | 上摇 | 仰视感、成长与上升意象 |
| `drift` | 轻微漂移 + 微旋转 | 手持呼吸感，让静态画面不死板 |
| `orbit` | 3D 环绕（rotateY） | 产品展示、3D 主视觉 |
| `static` | 不动 | 数据密集或需要细读的画面 |

转场对应的经典手法：

- `fade`：溶接，情绪连续、节奏舒缓。
- `slide`：模拟甩镜（whip pan），能量高，适合快节奏。
- `wipe`：划变，章节切换。
- `none`：硬切（cut）。放在节拍重音上最有力。

## 节奏规则

1. 一个场景只用一种运镜，全片不超过 3–4 种。
2. 相邻场景交替方向（pan-left 之后接 pan-right 或 push-in），避免同向堆叠产生晕眩。
3. 开场用 `push-in` 建立注意力；片尾用 `pull-out` 或 `static` 收稳，不在 CTA 上做大幅运动。
4. 文字越多，运动幅度越小；数据页优先 `push-in` 或 `static`。
5. 有 BPM 时剪辑点自动对齐节拍；高能量段落可用更短的场景（2 拍或 4 拍）。

## 大师风格的落地方式

用户提到某种电影风格时，翻译成现有参数，不承诺做不到的效果：

- **韦斯·安德森**：对称居中构图、`static` 或横向 `pan`、`editorial` 风格加糖果色 `brand.colors`、硬切。
- **苹果发布会**：`keynote` 风格、大字少字、`push-in`、溶接、大量留白。
- **诺兰 / 史诗感**：`keynote` 或 `aurora`、`cinematic` 配乐、`pull-out` 揭示、`orbit` 3D。
- **MTV / 潮牌快剪**：`kinetic` 风格、`slide` 转场、2 拍一切。

模板片不做景深追焦；需要焦点转移、运动模糊、3D 穿越时改用 Film 模式（`Gallery3D`、`Carousel3D` 的 `DepthOfField`，`CameraMotionBlur`）。真实镜头畸变、希区柯克变焦等需要实拍素材的效果留到第二阶段接入 Seedance 生成镜头。
