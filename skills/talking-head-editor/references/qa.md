# 成片检查

你看不了视频、听不了声音，就用截图拼图和测量代替，最后请用户看一遍。

## 1. 看排版：关键节点截图

```bash
python scripts/contact_sheet.py out/final.mp4 --every 2            # 全片概览
python scripts/contact_sheet.py out/final.mp4 --at 0.5 3.2 8.1     # 指定关键节点
```

逐张看：

- 大字有没有压在脸上；字幕和卡片、小窗有没有互相挡住。
- 每个关键节点的画面单独拿出来，排版是否成立（高级感要像一张海报）。
- 同一时刻是不是只有一个视觉焦点。
- 卡片样式、字幕位置全片是否统一。
- 有没有黑屏、错位、素材没铺满露出黑边。
- 有没有漏打的隐私信息（人脸、号码、密钥、二维码）。

## 2. 看节奏：时间分布

- 列出所有 B-roll、版式切换、推近、大字的时间点，检查有没有超过 8 秒（综艺感 5 秒）什么都没变化的口播全屏段。
- 同一种包装是不是连续用了 3 次以上。
- B-roll 占比是否符合方案（信息卡片式 50%~65%）。

## 3. 听声音：测量

```bash
ffmpeg -i out/final.mp4 -af ebur128 -f null - 2>&1 | grep -E "I:|Peak"
```

- 整体响度在 -16 ~ -14 LUFS 之间，峰值不超过 -1 dB。
- 抽几段只有配乐的地方（开头、留白）和有人声的地方对比，配乐不能盖过人声。

## 4. 读字幕

- 导出 timeline.json 里所有字幕文字通读一遍：错别字、专有名词大小写（Claude Code、GitHub）、数字和单位。
- 字幕和口播对不上的地方（用户说的和稿子不一样）以录音为准。

## 5. 请用户看

把成片（或预览版）发给用户，同时附上：
- 用了哪些 B-roll、来源（自己的 / 素材库 / 生成的，花了多少积分）；
- 打了码的位置；
- 你拿不准、希望用户确认的地方（比如重录选了哪一遍）。

用户提修改意见时，改 timeline.json 后重新渲染，不要从头再来。
