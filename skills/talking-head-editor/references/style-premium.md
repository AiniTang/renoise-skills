# 高级感包装

参考两类头部知识口播：信息卡片式的财经知识口播、人物大字报式的字幕教程。核心是**做减法**：观众只需要记住几个关键词，其余让它安心当台词；画面靠层次和缓慢运动显得贵，而不是靠特效多。

## 判断标准（渲染后自查用）

| 标准 | 做到了是什么样 | 没做到是什么样 |
|---|---|---|
| 信息有主次 | 每 10~20 秒最多一个关键词大字，重点句约占 10%~20% | 每句都在变色、都在弹 |
| 画面有层次 | 背景、素材、人物、文字、头像分层，非主体压暗 | 所有元素平铺在同一层 |
| 运动慢 | 背景缓推、卡片缓升、关键帧带缓动 | 到处弹跳、抖动、闪烁 |
| 克制 | 1~2 种字体、不超过 3 种颜色、几乎不用贴纸 | 多色花字、综艺贴纸、人脸特效 |
| 统一 | 全片两三种固定构图，卡片同一模板 | 每段一个样子 |
| 关键帧像海报 | 关键节点截图出来排版好看 | 字挤满屏，像 PPT |

## 两种版式

**人物大字报式**（观点、方法论、个人经验）
- 口播为主，关键词大字放人物两侧或头顶，2~4 个字一个，配一行小号英文或拼音副标。
- 一句话里的关键词换强调色，其余白色。
- 字可以压在人身后（「字在人后」，见 recipes.md），形成前后景。
- 章节之间插一屏大字章节页（整屏一个词或编号 POINT 01）。

**信息卡片式**（知识、财经、科普、新闻）
- 人缩成角落的圆形头像（pip，直径 0.22~0.28，放右上或右下），主画面给 B-roll。
- B-roll 占 50%~65%：新闻截图卡片、数据图形、报告页、空镜。
- 横版素材统一双层构图，截图统一圆角卡片，全片固定位置。
- 口播全屏只留在观点、情绪、转折处。

开头和观点段用大字报式建立人设，讲事实和数据切信息卡片式。

## 字幕

| 等级 | timeline 写法 | 规则 |
|---|---|---|
| 口播底字 | subs, level=base | 半透明黑色圆角底条 + 白色思源黑体粗体，胸口偏下位置，一句一屏 7~12 字；碎碎念可以不出字 |
| 重点句 | subs, level=key, hl=[关键词] | 字大一号、底条更深，强调词换特粗，不变色；颜色留给大字 |
| 框架概要 | titles，`chapter` 章节页、`mix` 角标标签 | 「01 版本管理」「POINT TWO」 |
| 关键词 | titles，`side` / `split` / `quote` | 人的一侧，不压脸，不压字幕 |

- 颜色：暖白 #F7F5F0 + 一个强调色红 #D7262D，最多再加半透明白做小字。全片不超过 3 种颜色。
- 字幕不描边、不发虚，靠底条在任何背景上都清楚；描边粗字是综艺感的语言。

## 字体与排版

字体全部是 OFL 开源授权、可商用，第一次用时自动下载（清单见 `assets/fonts/README.md`），脚本按角色自动选用：

| 角色 | 字体 | 用在哪 |
|---|---|---|
| sub | 思源黑体 Bold | 跟读字幕 |
| sub_key | 思源黑体 Heavy | 重点句里的强调词 |
| body | 思源黑体 Medium | 引子小字、说明 |
| title | 思源黑体 Heavy，横向压窄到 82% | 关键词大字：压窄后就是教程里窄长粗标题黑的感觉 |
| serif | 思源宋体 Heavy | 金句 |
| hand | 马善政毛笔楷书 | 书法大字点缀 |
| note | 志莽行书 | 手写批注（「划重点」「翻车现场」） |
| en | Oswald SemiBold | 英文小标、拼音标注 |
| en_display | Anton | 章节号、巨字底纹、数字 |
| en_serif | Instrument Serif Italic | 英文斜体副标 |

排版的高级感来自对比和不对称，不来自装饰（不要再用居中的「编号 + 标题 + 细线 + 小字」，那是最典型的 AI 模板）：

- **放在人的一侧**：字块贴左或贴右，人在另一边，画面像海报。
- **大小对比**：一行小字引子引出大关键词，字号差 3~4 倍；关键词一行 2~4 个字。
- **红白两色**：关键词里最要紧的那个词用红色，其余暖白。
- **中英混排**：关键词下面一行英文斜体衬线或拼音小标。
- **书法和手写点缀**：一组画面里最多一处，小角度倾斜。
- **层次**：背后叠半透明超大英文（`ghost`），或字在人后（`behind`）。
- **柔和投影代替描边和底框**。

用户有品牌字体或自己装了优设标题黑、阿里妈妈东方大楷这类不能随 Skill 分发的字体，写进 timeline 的 `fonts`（如 `"title": "优设标题黑"`）。

## 构图与层次

- 主信息出现时其余全部压暗：aside 版式自带虚化压暗背景；卡片出场可以配 `motion: rise`。
- 版面留白：卡片宽度 0.8~0.9，上下留空间；字幕和卡片不重叠（卡片 y 0.35~0.5，字幕 y 0.8）。
- 四角构图：四个关键词放四角依次出现，适合「四个原因」这类并列。
- 左右分立：两个关键词分在头的两侧（`split`），适合对比。

## 信息包装（做法见 recipes.md）

新闻卡片、荧光笔划线、数据卡片（数字滚动、柱状图）、报告纸页、时间轴、左右对比、定格暂停、金句卡。全片同一套卡片样式：同样的圆角、投影、底色、字体。

## 防审美疲劳（每一层按自己的节拍变）

一条头部财经知识口播全片只有两种版式、底字样式不变，但画面平均 2.4 秒就有一次新东西：框不动，框里的东西一直换。Skill 里大部分已经自动做：

- 口播景别三档跳切（自动）：每次回到口播换一档，口播全屏单段不超过 8 秒。
- 卡片上浮、图片缓推（自动）：画面一直在极慢地动。
- 章节转场、配乐留白（自动）：只在章节点，轮换不重复。
- 音效（自动 + 你标）：章节、素材出场、大字自动配；画面里有动作或口播说到关键词时，你在 sound / sounds 里标一个对得上的声音。
- 大字：相邻两个大字在版式、左右、字体里至少换一样，重包装约 15 秒一处。
- 贴纸：每分钟最多 1 个，必须对着一个具体的词。

渲染前跑 `scripts/rhythm_check.py`，按它列的时间点补变化。完整依据见知识库「防审美疲劳手法」。

## 运动

- 背景和素材保持缓慢持续运动：图片缓推（push），卡片缓升（rise），口播段落收尾缓推。
- 重点处才用快速推近（0.12 秒推到 1.08~1.15）。
- 转场少：默认硬切；章节之间可以用动态模糊转场或留白转场。
- 入场动画统一：卡片渐显或上滑，大字从侧边模糊渐清滑入、每行错开 0.07 秒（`blur_in`），全片不超过 3 种入场方式。弹出是综艺感的动作。

## 声音

- 配乐：有清楚鼓点、不抢人声的纯音乐（Lo-fi hip hop、downtempo、轻电子），从免版权曲库挑，画面切换卡在节拍上。
- 音效：大字出现配一声轻扫风声，章节页配一声短低音，脚本自动加；每分钟 3~8 个，不用提示铃。
- 留白：段落之间音乐收住、画面点出主题，0.3~1 秒。

## 不要做

- 人脸综艺特效、综艺贴纸、多色花字；
- 每句话都换颜色或都加动画；
- 卡片样式每段不同；
- 大字压在脸上。
