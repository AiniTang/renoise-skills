# 单形状宣传片（One-Shape Morph）

一个形状从头到尾不切镜头，同一个元素在尺寸、圆角、颜色之间连续变形，内容用短模糊替换；一个光标用真实的点击和拖拽驱动每次变化；最后一帧等于第一帧，可以循环。默认做成**宣传片版**：形状是主线，外面包一层宣传片骨架。

| 形式 | 画幅 | 结构 | 示例 |
|---|---|---|---|
| 宣传片版（默认） | 16:9，约 20 秒 | 1 小节钩子 + 7 小节主线 + 2 小节收尾，左侧大字卖点 | `examples/morph-promo/`（给技能自己做的宣传片，124 BPM，信号橙） |
| 纯循环版 | 1:1 1440×1440，约 14 秒 | 严格 7 小节，只有形状和光标 | `examples/morph-loop/` |

纯循环版只是一串 UI 演示，没有钩子、卖点和行动号召；用户要"宣传片"时一定用宣传片版。

## 开始前

先要输入，再把状态清单排到节拍网格上给用户确认，确认前不写代码：

1. 8–12 个 UI 状态。每个状态必须是产品流程里真实的一步（输入需求、分析、选风格、选曲、导出……），不要通用组件；用户没给就按卖点拟。
2. 纯黑白，或黑白加一个强调色。
3. 约 120 BPM 的可商用曲子（内置曲库；`pick_music.py --bpm 124` 强制整数速度）。

网格表每行一小节：形状状态 / 每拍动作 / 左侧大字。

## 宣传片骨架

- **左侧文案列**（x < 700）：步骤编号小字（`01 需求`）+ 两行大字（Geist 700，约 92px），第二行关键词用强调色。第一行在小节第一拍进，第二行晚半拍；下一小节开始时模糊退出。文案讲卖点，形状演证据。
- **钩子**：第一小节就给出一句话价值（"一句话，做一条宣传片。"），形状是可点的按钮。
- **收尾**：导出/完成的提示条 + 产品名大字，最后变回第一帧的按钮和文案，整片仍能循环。
- **镜头**：形状中心在右侧（x≈1300）。每个状态按 `min(1040 / w, 860 / h, 2.3)` 撑满；点击和拖拽时推近 10% 并向光标偏 15%；再用 `MAX_W / w` 限宽，推近时不压到文案列、不出右边缘。一次"甩镜"（焦点瞬移再弹回）配 whoosh，可以展示运动模糊。
- **密度**：严格每拍一个动作，不许把 7 小节拉长；每个状态最多停一小节。

## 方向

- 暖灰画布（`#ECEAE6`），黑白组件，Geist 字体（`npm i geist`，取 `dist/fonts/geist-sans/*.woff2`，用 `src/cinematic/geist.ts` 加载；中文回落苹方）。
- 处处是弹簧，最多一点点过冲（阻尼约 0.82）。
- 禁用：夸张回弹、粒子、辉光、界面上的渐变、不一致的图标线宽、空拍、模板感。这是 motion-craft.md 的「精密 UI 档」。

## 实现（Remotion）

- **弹簧是时间的纯函数**：`src/cinematic/spring.ts` 的 `step()` 是闭式阶跃响应；`track` 把每次改变目标叠成一个弹簧；`trackColor` 按 RGB 通道叠加；`trackCfg` 允许每次改变用不同的弹簧。
- **一个形状**：一个 div，`width / height / borderRadius / background` 全由 `track` 驱动，`overflow: hidden`；每个状态的内容是一层，0.2 秒模糊进、0.1 秒模糊出，进出时间和变形错开，否则新旧文字重叠。上一个状态的元素可以直接变成下一个（灵动岛的圆点变成选项卡指示条，开关圆钮变成指示条）。
- **世界坐标**：形状中心为原点，外层 `scale(cam) translate(-focus)`；光标画在屏幕空间（`CX + (x - focusX) * cam`），不随镜头变大。
- **光标**：关键帧 `[时间, x, y]` 用临界阻尼弹簧插值。要按下或拖拽的目标，光标至少提前 0.5 秒出发，否则按下时还没到位，拖拽值会跳。
- **拖拽是直接操控**：`dragged(t, [按下, 松开], live, 拖前值, 松手后值)`；拖前值要等于光标抓住的位置。拖过上限用橡皮筋 `260 * (1 - exp(-over / 260))` 拉长容器，只向拖动方向长。
- **双弹簧边缘**：指示条/圆钮左右两边各走一个弹簧，移动方向那边用 `LEAD`，另一边用 `TRAIL`。
- **声音**：UI 音效按接触帧排，`SoundCues` 自动按实测峰值提前。拖过刻度的"嗒"声，按 240 Hz 采样光标驱动的值找出越过刻度的时刻。
- **真实数据**：波形用配乐的 RMS 包络（numpy 切 72 段存 `wave.json`）。
- **循环**：首个关键帧的值等于最后的目标值；最后一次变化至少在结尾前 0.9 秒开始，光标回到起点停稳；首末帧逐像素比较（允许运动模糊的 ±2 误差）。
- **渲染**：`fps={60}`，外层 `CameraMotionBlur samples={4}`；先每拍渲一帧（拍后约 0.37 秒）拼图检查，修完再整片渲染。

## 坑

- 不要给被镜头缩放的元素加 `will-change`，文字会糊。
- 定位用的 `translate` 和动画用的 `transform` 分到两层 div，否则动画覆盖锚点，右对齐文字被裁。
- 零宽容器里的绝对定位文字会被压成最窄宽度而折行，文字块一律 `whiteSpace: nowrap`。
- 拼图缩小后会误判尺寸，怀疑镜头时渲原尺寸帧量像素。
