# 两种风格怎么选

两种风格共用同一套流程（素材检查、转写、粗剪、剪辑方案、B-roll、声音、检查），只在包装层分叉。

| | 高级感（默认） | 综艺感 |
|---|---|---|
| 适合 | 知识科普、财经、行业分析、方法论、个人品牌 | 轻松吐槽、生活经验、新手教程、强人设的娱乐向账号 |
| 观感 | 干净、有质感、关键画面像海报 | 热闹、密集、情绪起伏大 |
| 字幕 | 分四级，颜色不超过 3 种，关键词大字配小号英文副标 | 重点句换彩色花字，出现频率高，描边粗 |
| 情绪放大 | 定格、留白、重音鼓、压暗背景 | 人脸特效、综艺音效、综艺贴纸、综艺文字模板 |
| 画面 | 多层叠放、缓慢运动、全片统一构图 | 素材直接给，节奏快，元素多 |
| 音效 | 少，只在转场和关键点 | 密，每分钟 10~30 个 |
| 推荐出口 | 成片或草稿都行 | 剪映草稿（人脸特效、花字、综艺模板都是剪映素材，代码只能近似） |
| 详细规则 | `style-premium.md` | `style-variety.md` |

## 高级感的两个强度档

高级感分两档，timeline.json 写 `"tone"`：

| | 网感档 `web`（默认） | 克制档 `calm` |
|---|---|---|
| 适合 | 知识干货、方法论、AI 工具、个人成长 | 财经、医疗、品牌片、严肃话题 |
| 手法 | 高级感手法加网感手法：打字机光标、标签卡、闪现入场、色块衬底、双词弹出 | 只用纯高级感手法：模糊渐显、宽字距英文以外的副标用斜体衬线 |
| 音效 | 每分钟最多 14 个，标签卡、并列项逐条配轻点击 | 每分钟最多 8 个，只在章节和关键点 |

网感不是第三种风格：它和综艺感的区别是不用人脸特效、综艺音效、彩色花字，信息密度高但画面依然干净。

## 怎么选

1. 用户指定了就用用户的。
2. 没指定默认高级感。
3. 内容明显是娱乐向（吐槽、搞笑、日常、强人设、语气夸张），在开工时建议一句：「这条内容挺轻松的，要不要用综艺感包装？会更热闹，适合导出剪映草稿再微调」，用户决定。
4. 同一条视频不混用两种风格。高级感视频可以在一两个包袱处加一点轻量情绪（一个表情、一声音效），但不要变成综艺感。

timeline.json 的 `style` 字段决定默认样式（字幕大小颜色描边、卡片圆角投影、小窗描边、配乐和音效音量），细节在 `scripts/kvlib.py` 的 STYLES，可以用 `style_overrides` 逐项改。
