# 风格路由：扩展包越来越多时怎么选

原则：**每支片只做四个选择，每层只选一个（增强层最多两个）**。不要把所有能力都堆上去，也不要每次把所有文档读一遍——先按这张表选定，再只读选中的那几份文档。

## 四层

| 层 | 选一个 | 选项 |
|---|---|---|
| ① 模式 | 片子是什么 | 电影级宣传片 / 模板片 / 个人品牌片 / 硬件概念片 / 作品合集 / 动效作品集 / 单形状片 / 品牌调性片 / 风格目录片（style-pack-05 / 06） |
| ② 视觉基调 | 看起来像什么 | 暗场科技快剪 / 浅色编辑（Apple）/ 浅色便当格 / 剪纸 / 瑞士网格动态字 / **标本册编辑风**（暗墨 + 暖纸交替、规格书 HUD，style-pack-03）/ **综艺花字** / **贴纸风科普** / **等轴 2.5D 微缩城**（style-pack-05）/ **逐帧手绘 · 一笔画 · 拼贴 · 扁平插画 · 包豪斯 · 液态 · 弥散玻璃 · 3D 软萌 · 赛博 HUD · 像素 · 合成波**（style-pack-06）/ 航海日志·印章等主题风（按品牌定制） |
| ③ 叙事骨架 | 镜头怎么串 | **快剪卖点**（一拍一个卖点）/ **场景三连**（场景 → 任务·过程·交付截图 → 已交付章，投流用）/ **一镜到底接力**（style-pack-02）/ **旁白驱动讲解** / **数据证明**（DataStory）/ **概念阶梯**（点→线→面→体→场，章节级接力，style-pack-03） |
| ④ 增强层（≤2） | 加什么料 | 音乐驱动 HitCam / 液态 / 无限穿越 / 透视揭示（style-pack-01）/ 动效图标 · 动态 emoji（animated-icons）/ 3D 设备 / 生成艺术标本 · 粒子聚成 Logo · 笔尖写 Logo（style-pack-03） |
| ⑤ 字体 | 用什么字 | 按 typography.md 定调性（精密科技 / 极简中性 / 人文温暖 / 编辑高级 / 奢华典雅 / 活力潮流 / 粗犷海报 / 友好圆润 / 手写温度 / 复古数字 / 东方诗意）→ 3 组配对 + 品牌现用字体出提案图（`fonts.py specimen`）→ 用户选 |

②和③互相独立：同一个「一镜到底」可以是暗场也可以是浅色；同一个「暗场快剪」可以串成场景三连也可以串成接力。

## 按信号选

| 用户的话 / 素材信号 | 推荐 |
|---|---|
| 「炫酷」「科技感」「高级质感」，SaaS / AI / 开发者工具 | ② 暗场科技快剪 + ③ 快剪卖点 |
| 「投流」「广告」「转化」，有多个使用场景 | ③ 场景三连，每场景 7 拍，结尾四宫格回顾 |
| 发来一支参考片，说「学这种感觉」 | 先拆参考片（0.25s 一帧拼图），归到③的某一骨架；没有就新建扩展包，先做样片 |
| 「一气呵成」「流畅」「丝滑」「不要硬切」，产品有输入→产出→持续运行链路 | ③ 一镜到底接力（style-pack-02） |
| 「讲清楚」「介绍一下功能」，要配音 | ③ 旁白驱动讲解，时间轴由 narrate_mimo.py 的逐字时间驱动 |
| 有真实数据（融资、增长、排名） | ④ DataStory，数字只用用户给的 |
| 「多合一」「整合」 | ④ 液态 |
| 硬件、App 内部结构 | ④ 透视揭示 / 3D 设备 |
| 课程、社媒、轻松向，用户想要 emoji | ④ 动态 emoji（Noto） |
| 音乐感强、节奏卡点 | ④ 音乐驱动，只用 HitCam 3–5 个关键帧 |
| 「Claude 那种」「官方质感」「品牌调性 / 品牌升级 / 品牌片」「不要具体功能演示」，产品有由小到大的层级 | ② 标本册编辑风 + ③ 概念阶梯 + 人文层（style-pack-03），约 60s、钢琴或弦乐；投流只借前两章做钩子 |
| 「N 种风格」「一个产品多种画风」「给我几种风格选」，或要展示我们的视频能力 | ① 风格目录片（style-pack-05）：每格 10s 样片 + 信息卡，圆点串联，片尾四宫格 |
| 投流 / 社媒、录屏里有「等等？！」的反应时刻，日韩市场 | ② 综艺花字（`variety/`），三拍：提问 → 加速（真实倍速）→ 震惊 |
| 「一个产品 N 种能力」「功能盘点」「科普」 | ② 贴纸风（`sticker/`），官网素材模切成贴纸 |
| 讲「搭建 / 生长 / 规模 / 生态」 | ② 等轴 2.5D（`iso/`），一块输入框地砖长出街区 |
| 温暖科普、吉祥物、「想法诞生」 | ② 逐帧手绘（`handdrawn/`）：姿势表一拍二替换 + 蜡笔排线 |
| 一个故事串起多个产出、极简编辑风 | ② 一笔画（`lineart/`）：线 = 答案，填色 = 成果 |
| 作品集、「我们做过的」、潮牌/杂志感 | ② 拼贴（`collage/`）：真实作品网点印刷 + 撕纸 + 盖章 |
| 品牌色 / Logo 演绎、消费品 | ② 液态（`glossy/`）或 3D 软萌针阵（`soft3d/`） |
| App / AI 助手界面、苹果系审美 | ② 弥散玻璃（`glass/`） |
| 数据 / Agent 控制台 / 游戏化 / 80 年代 | ② 赛博 HUD（`fui/`）/ 像素（`pixel/`）/ 合成波（`retro/`），配各自的合成配乐 |
| 模型/产品发布概念片，要展示能力与"和对手的区别"，官方口径可引用，名字能做文字游戏 | ② 暖纸 ⇄ 暗场 + ③ 十四行诗骨架 + 3D 景深 + 68 万笔画 GPU 奇观（style-pack-04）；不点名对手，只引官方原话 |
| 「字体常规」「不够设计感」「不符合调性」，或官网用的是商业字体 | ⑤ 字体提案：`fonts.py pairs --tone` 选 3 组 + 品牌现用 1 组，`fonts.py specimen` 用真实文案出图；商业字体先 `fonts.py similar` 找平替（typography.md） |

冲突时的优先级：**用户明确说的 > 该用户的口碑记录（下表）> 行业默认（industries.md）**。

## 选型卡（写在分镜表上方，和分镜一起给用户确认）

```
选型：电影级 · 暗场科技快剪 · 一镜到底接力 · 动效图标
字体：精密科技 · Geist × Geist Mono（中文 思源黑体，日文 M PLUS 2）· 提案图 out/type-proposal.png 用户选了第 2 组
为什么：用户说「学这支参考片」；产品有 输入→处理→产出→每天自动跑 的链路；用户偏好暗场（口碑记录）
要读：style-pack-02.md、animated-icons.md、typography.md（其余不读）
不用：音乐驱动整段抖动（用户反感）、Apple emoji（版权）、系统字体当主字体（授权）
```

一张卡五行，用户一眼能看出这支片「是什么路子」，不同意就在这一步改，不用等样片出来。

## 扩展包的生命周期

1. **新手法进来**（参考片、社区作品）：拆解 → 写成 `style-pack-NN.md` + 组件 → 用一个真实客户素材做样片。
2. **样片验证**：组件必须能独立复用（示例片只用组件重写一遍，和手写版逐帧对比）。
3. **进路由表**：在「按信号选」加一行触发信号；在口碑记录加一行。
4. **降级或合并**：连续两次用户反馈一般的组合，从推荐里拿掉（文档保留）；两个包手法重叠时合并。
