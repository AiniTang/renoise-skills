# 口播视频剪辑

把一段或多段真人出镜素材（A-roll）剪成节奏紧、信息清楚、有质感的口播视频，竖屏（抖音、视频号、小红书）和横屏（B 站、YouTube）都支持。剪辑决策（每句话怎么处理）由你来做，重复劳动交给 `scripts/` 里的脚本。

## 先建立三个认识

1. **口播视频的上限由 B-roll 决定**。信息卡片式的财经知识口播，口播全景只占约 30% 时长，约 65% 是 B-roll 和信息卡片。大多数用户只有 A-roll，所以你的核心价值之一是逐句判断该配什么画面，并把它找来、做出来或生成出来。
2. **风格只改包装，不改骨架**。两种风格共用同一套流程：素材检查 → 转写 → 粗剪 → 剪辑方案 → B-roll → 包装 → 声音 → 渲染 → 检查。高级感和综艺感只在字幕、情绪放大手段、画面层次上分叉。
3. **一份时间线，两个出口**。所有剪辑决定写进 `timeline.json`，同一份文件既能用代码渲染成片，也能生成剪映草稿，两边内容一致。

## 开工前问清楚（一次问完，有默认值的直接用默认）

| 问题 | 默认 |
|---|---|
| 交付什么：成片 MP4、剪映草稿、还是都要 | 成片 MP4；用户提到剪映或想自己微调时给草稿 |
| 风格 | 高级感。内容是轻松吐槽、生活经验、强娱乐人设时，主动建议综艺感，由用户决定 |
| 高级感的强度档 | 网感档：节奏快、信息密，用打字机、标签卡、闪现这类手法；内容很严肃（财经、医疗、品牌片）时建议克制档 |
| 画幅 | 跟着素材走：竖着拍出 9:16 竖屏 1080×1920，横着拍出 16:9 横屏 1920×1080，30fps；用户要发的平台和素材方向不一致时问一句。横屏时人在画面中间，大字、卡片放两侧，字幕在底部中间，所有手法会自动按横屏重排，`--canvas` 写法见 `references/timeline.md` 开头 |
| 有没有现成的 B-roll（截图、录屏、照片、产品素材） | 没有就按第 5 步补齐 |
| 用什么配乐：请用户给一首自己喜欢的曲子（文件或曲名） | 用户没有时，从免版权曲库挑三首候选做成试听片，用户选定再用 |
| 允不允许花 Renoise 积分生成素材 | 先不花；需要时报价再问 |
| 有没有逐字稿 | 没有就以转写为准 |

两种风格的区别和选择依据见 `references/styles.md`。

## 工作目录

每个视频一个项目目录，中间产物都落盘，方便返工：

```
<项目>/
  check.json          素材检查报告
  transcript.json     转写（逐字时间）
  edl.json            粗剪保留段
  aroll.mp4           粗剪后的口播
  lines.json          粗剪后每句话的新时间
  plan.md             给用户看的逐句剪辑方案
  timeline.json       给脚本吃的时间线
  broll/              B-roll 素材
  sfx/ bgm/           音效与配乐
  out/final.mp4       成片
  out/draft/          剪映草稿（可选）
```

脚本依赖：`ffmpeg`（带 libass）、Python 3.10+、`pip install -r requirements.txt`。开工前先跑 `python scripts/doctor.py`，它列出缺什么、怎么装。字体用的是中英文 20 多款开源可商用字体，脚本按角色自动选用：高级感很大程度靠字体，系统自带字体做不出来。字体不随 Skill 分发，第一次渲染时自动从发布方下载约 80 MB 并核对校验值，没网的环境先在有网时跑 `python scripts/fonts.py fetch`。抠像模型第一次用时自动下载，依赖的 onnxruntime 本机没装会自动用 `uv run` 临时装；敏感信息识别依赖较重，也用 `uv run --python 3.12 --with ...` 临时装（命令见脚本开头）。自动配音效用 earshot 的代码音效库，第一次先跑 `python scripts/setup_earshot.py install`（没装会退回 Mixkit 音效）。用户电脑配置不够或没有本地环境，而接了 Renoise MCP 时，可以在 Renoise 的云端剪辑沙箱（`sandbox` 工具，订阅用户可用）里跑：把 Skill 和素材传上去，在沙箱里执行同样的脚本。

## 流程

### 0. 没有拍摄素材时

用户没拍、不想出镜，或者想用自己的形象说一段新稿子：先用 Renoise 生成数字人口播当 A-roll，再从第 2 步转写开始剪。三条路线怎么选、参考素材怎么准备、生成后要查什么，见 `references/digital-human.md`。生成要花积分，先报价、用户同意再生成。

### 1. 素材检查

运行 `python scripts/check_media.py <口播素材...> --broll <截图录屏...> -o check.json`，看分辨率、帧率、横竖屏、时长、音量（LUFS）、底噪和爆音。有问题当场告诉用户（例如「声音偏小，会统一提升到 -16 LUFS」「这段对焦一直在跳」），能修的自己修，修不了的建议补拍。B-roll 只查画面，标出带透明底的素材（它们只能叠放，不能铺满）。细节见 `references/intake.md`。

### 2. 转写

运行 `python scripts/transcribe.py <口播素材...> -o transcript.json`。脚本按静音切成「语音岛」后逐岛识别，避免整段识别把重录的半句话并进正文、或在纯音乐段反复输出同一句幻觉。专有名词多时用 `--prompt` 传入词表。用 whisper.cpp 时只有每段的起止时间准，段内逐字时间是按字数摊开估的，B-roll 要卡某个词时留 0.2 秒余量，或换 faster-whisper 拿真逐字时间。

### 3. 粗剪

先 `python scripts/auto_edl.py transcript.json -o edl.json --breath premium_breath` 起草粗剪单（重录留最后一遍，半句和语气词删掉），再读 transcript.json 核对它删的对不对，改好错字、加好标点、调顺序（高级感用 `premium_breath` 留气口，网感用 `web_tight` 紧剪），然后运行 `python scripts/rough_cut.py edl.json -t transcript.json -o <项目>` 得到 `aroll.mp4` 和 `lines.json`，然后 `python scripts/init_timeline.py <项目> --style premium` 生成带自动断句字幕的 `timeline.json` 骨架。判断规则（同一句录了几遍留最后一遍、句间留多少气口、要不要整体提速）见 `references/rough-cut.md`。

### 4. 逐句剪辑方案（最重要的一步）

按 `references/plan.md` 的方法，先按结构切段（开场、第一点、第二点…结束语，写起止、情绪、包装建议），再给每一句决定：字幕等级、版式（口播全屏 / 人物移出 / 圆形小窗 / 信息卡片）、要不要 B-roll 以及从哪来、包装手法、音效。写成 `plan.md` 表格给用户过目，再生成 `timeline.json`（格式见 `references/timeline.md`）。

也看整条片子是否首尾闭环：开头承诺了「6 个坑」而素材只讲到第 2 个，就在方案里点出来，建议补素材或标成上集；结尾太突然用 `tail` 留 1~2 秒放片尾字和配乐收尾。

**这一步要停下来让用户确认方案**，因为改方案很便宜，改成片很贵。用户说「你看着办」就直接往下做。

关键词大字不用逐条手写版式：在 timeline.json 里写 `beats`，每段话标一个内容类型（并列、对比、数字、金句、新概念、提问……）并给出要上屏的字，渲染时代码从**手法库**里按风格、强度档和防审美疲劳规则挑手法和变体，按口播逐字时间对齐出现时刻。手法库来自 26 个口播剪辑教程和 10 个剪映草稿，共 212 条手法，已实现的用法和还没实现的清单在 `references/library.md`（`python scripts/library.py menu --beat list` 看某类内容能用什么）；挑完用 `python scripts/library.py arrange timeline.json` 查看，不满意就写 `use` 指定手法。数据卡、占比环形图、章节页也在 beats 里自动挑（标 `evidence`、`number`、`chapter`），章节页全片只用一种载体。画面与镜头、版式类手法（口播缩成卡片、圆形收缩成小窗、分屏对比、网格点阵底、横版素材带、透视卡、缓推、手机样机、头像图文版、目录回顾、关注尾帧、纸页飞入、素材卡边框、截图划重点）不跟内容走，按画面节奏写进 `layout`、`broll`、`zoom`，可写的值在 `references/library.md` 的「写在 timeline 字段里的手法」一节和 `timeline.md`；开场第一秒冲击、背景压暗、句首快推、小窗高潮让开、相接卡片同向衔接、章节页上字幕让开这几样渲染时自动做。

具体手法怎么搭配，翻 `references/recipes.md`（手法示例库，每个手法带适用场景、参数和两条路线的做法）。

### 5. 补齐 B-roll

按优先级：用户自己的截图录屏 → 代码做的动画和图表（`scripts/make_graphic.py`：数字滚动、柱状图、左右对比、步骤清单、时间轴、金句卡、截图荧光笔划线）→ 公开可商用素材库（`scripts/broll_search.py`，需要 Pexels 或 Pixabay 免费密钥）→ Renoise MCP 生成。做法、提示词、版权边界都在 `references/broll.md`。

用 Renoise 生成会花用户积分：先用 `estimate_cost` 报总价和余额，等用户在对话里明确说可以再生成。视频默认 Wan 3.0，用户点名才用 Seedance 2.5；带文字的信息图用 GPT Image 2.5；写实图片用 Seedream 5.0 Pro。

### 6. 敏感信息检查

截图、录屏、口播画面里经常带着邮箱、手机号、姓名、证件号、银行卡号、地址、二维码、API 密钥。运行 `python scripts/detect_sensitive.py <素材或目录> -o sensitive.json`，再结合 transcript.json 看口播里有没有念出这类信息。

发现了就列出来（在哪个文件、第几秒、是什么）并问用户要不要打码，**不要擅自决定**：有些信息是用户故意展示的（比如自己的公众号二维码）。用户同意后用 `scripts/mask.py` 处理素材（口播里的就处理 aroll.mp4），再把 timeline.json 里对应的 src 换成打码后的文件。用户事先说过「中间别问我」时，先不打码把片子做完，交付时把这些发现放在说明的第一条，请用户发布前确认。细节见 `references/privacy.md`。

### 7. 包装

按风格施加包装：字幕、关键词大字、信息卡片、画中画、关键帧运动、转场。用到抠像的手法（字在人后、换底、人缩角、出框）渲染时自动抠，不用另外准备人像。
- 高级感：`references/style-premium.md`
- 综艺感：`references/style-variety.md`

### 8. 声音

人声降噪、去齿音、压缩并统一响度，渲染时自动做。配乐按段落排：开头高一档正文压低、人说话自动让开，用户给了几首曲子时按段落情绪换曲，换曲用交叉淡化、嗖一声或留白接上。配乐优先用用户自己给的曲子：配乐的口味因人而异，Agent 挑的很难让用户满意。用户没有时，从公开免版权曲库下载候选、用 `scripts/music_score.py` 按节奏感排序，取前三首各配同一段画面做成试听片，**让用户选定再用**，不要自己挑了直接进成片（用户事先说了「中间别问我」，就用打分第一的那首，并在交付说明里写明配乐是临时选的、附上另外两首候选）；不用 AI 生成音乐。配乐定了再跑 `scripts/beat_sync.py` 让画面切换卡在节拍上。大字音效按风格自动配。规则见 `references/audio.md`。

### 9. 输出

- 成片：`python scripts/render.py timeline.json -o out/final.mp4`，先加 `--preview` 出一版低清快速预览自查。
- 剪映草稿：`python scripts/build_draft.py timeline.json --name <草稿名>`，剪映版本差异、坐标换算、能用和不能用的剪映素材见 `references/jianying.md`。Mac 版剪映不能自动导出，告诉用户打开草稿后自己点导出。草稿按这个顺序摆轨道，用户在剪映里接着改也照这个组织：从下到上主轨口播、B-roll、调整图层、网点丝印、素材带、包装（每个包装一个复合片段，同在一条轨）、头像、字幕；要人压字就开自由层级，口播复制一层做智能抠像、文字放两层之间；文字要加特效滤镜蒙版先转复合片段，转之前先定稿。

### 10. 成片检查

渲染前先跑 `python scripts/rhythm_check.py timeline.json`，把不合格的地方改掉再渲染；渲染后加 `--video out/final.mp4` 再跑一次，结果写进交付说明。声音用 `render.py --stems` 加 `scripts/audio_check.py` 核对（响度、配乐让人声、每个音效差几帧，出频谱检查图）。然后按 `references/qa.md` 自查：抽关键节点截图看排版、关掉画面只听节奏、关掉声音只看字幕、核对错别字和敏感信息。你看不了视频，就用截图拼图（`python scripts/contact_sheet.py out/final.mp4`）和音量测量代替，然后请用户看一遍。学别人的成片或复盘自己的成片时跑 `python scripts/teardown.py 成片.mp4 --timeline timeline.json`：数包装点和平均间隔、算口播全屏和画中画的时长占比、找配乐的停顿和换段。

## 几条底线和原因

- **字幕以用户说的话为准**。转写错字要改，但不改用户的意思、不替用户加没说过的话；逐字稿和录音不一致时以录音为准并标出来。
- **只用能商用的素材**。素材库只用明确可商用的（Pexels、Pixabay 等），不用影视剧、别人视频里的片段，新闻截图只作为评论引用且注明来源。剪映自带的花字、音效、特效只在剪映草稿里用，不打包导出给别人。
- **花钱之前先问**。生成素材、配乐、音效都花用户积分，报价确认后再动手。
- **敏感信息先问再打码**。原因见第 6 步。
- **每一步的产物都要能被用户看懂**。plan.md 用大白话写清每句话怎么处理，不写内部字段名。
