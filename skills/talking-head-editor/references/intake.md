# 需求确认与素材检查

## 开工前问清楚

一次问完，用户没说的用默认值，别反复追问。

| 问题 | 默认 | 为什么要问 |
|---|---|---|
| 交付成片 MP4、剪映草稿还是都要 | 成片 | 想自己微调的人要草稿；剪映 Mac 版不能自动导出，草稿需要用户自己点导出 |
| 风格：高级感还是综艺感 | 高级感 | 内容轻松搞笑、强娱乐人设时建议综艺感，由用户定 |
| 发在哪个平台、画幅 | 抖音、小红书、视频号竖屏 9:16 | 横屏（B 站、YouTube）要改 canvas 为 1920×1080，版式规则不变 |
| 目标时长 | 按内容自然长度 | 有硬上限（如 60 秒）时粗剪要更狠 |
| 有没有 B-roll（截图、录屏、照片） | 没有 | 决定第 5 步要补多少 |
| 能不能花 Renoise 积分 | 先不花，需要时报价再问 | 生成花钱 |
| 有没有逐字稿、专有名词 | 无 | 专有名词传给转写的 `--prompt` 能大幅减少错字 |
| 账号署名、系列名 | 无 | 片尾署名、章节标题会用到 |
| 喜欢的参考视频 | 无 | 有参考就按参考的版式和节奏来 |

## 素材检查

```bash
python scripts/check_media.py 口播1.mov 口播2.mov broll/* -o check.json
```

脚本会给出大白话的问题清单，按下面处理：

| 问题 | 处理 |
|---|---|
| 声音偏小（低于 -24 LUFS） | 渲染时自动响度标准化，不用管 |
| 底噪大 | 默认降噪（`audio.voice.denoise`），严重的建议重录或用 Renoise 沙箱里更强的降噪 |
| 爆音（峰值接近 0 dB） | 修不回来，告诉用户哪几段爆了，严重的建议补录 |
| 横屏口播 | 做竖屏会裁掉两边，确认人在画面中间；人偏的话粗剪时改裁切位置 |
| 分辨率低于 1080P | 铺满会糊，尽量少用推近；B-roll 低清的用卡片小尺寸放 |
| 截图分辨率低 | 卡片别放太大，或请用户重截原图 |
| 帧率低于 24 | 画面会卡，告诉用户 |
| 静音占比高 | 正常，粗剪会去掉 |

再人工抽看几帧（`contact_sheet.py 口播.mov --every 10`）：人是否在画面中间、光线是否稳定、背景有没有不该露的东西、有没有隐私信息。

## 多段口播

用户分段录的（「口播 01.mov」到「口播 07.mov」）或一条长录的都可以，转写和粗剪脚本都支持多文件。按文件名顺序默认就是内容顺序，不确定时问用户。
