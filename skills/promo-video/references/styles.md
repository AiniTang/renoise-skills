# 风格预设

`storyboard.json` 的 `style` 取以下之一。预设定义在 `src/theme.ts`，包括配色、字体、字重、转场、默认运镜、文字动画和节奏。

| 预设 | 画面描述（推荐给用户时使用） | 文字动画 | 默认转场 | 适合 |
|------|------------------------------|----------|----------|------|
| `keynote` | 发布会式极简：纯黑底、大字号白字、克制的蓝色光晕、缓慢推近 | 模糊渐显 | 淡入淡出 0.5s | 高端科技、金融、制造、B2B |
| `kinetic` | 动态排版：高对比黑底荧光绿、网格背景、文字弹出、滑动快切 | 弹跳出现 | 滑动 0.3s | 消费品、社媒广告、年轻受众 |
| `aurora` | 渐变极光：深蓝底上流动的紫青光斑、毛玻璃卡片、柔和漂移 | 上浮渐显 | 淡入淡出 0.6s | AI / SaaS、创新产品 |
| `editorial` | 杂志质感：暖白纸张底、衬线大标题、深青点缀、安静的节奏 | 上浮渐显 | 淡入淡出 0.6s | 医疗、教育、文旅、人文品牌 |

## 品牌色覆盖

`brand.colors` 覆盖预设颜色：

- `primary` → 主强调色（3D 主体、图表高亮）。非 aurora 风格同时作为高亮文字色。
- `accent` → 第二强调色。aurora 风格下同时作为高亮文字色。
- `background` / `text` / `muted` → 背景、正文、次要文字色；第二背景色由 `background` 自动推导。改动后必须看样帧确认对比度。
- `button` → CTA 按钮色，默认等于 `primary`。
- `dark` / `light` → 场景 `tone` 切换时的底色，用来还原官网的明暗区块节奏。

还原官网调性时，先看官网是浅底还是深底：浅底选 `editorial`，深底选 `keynote`，再用 `brand.colors` 和 `brand.fonts` 覆盖成品牌值。

品牌色与深色背景对比度不足时（例如深紫配深蓝底），高亮文字会看不清：在样帧里检查，必要时让 `accent` 用更亮的品牌辅助色。

## 字体

- 用户提供字体文件：放到 `public/brand/`，设置 `brand.fonts.display` / `brand.fonts.body`（`family` + `file`）。标题与正文可以是两套字体；`brand.displayWeight` 调标题字重。
- 未提供：使用系统字体栈（SF Pro / PingFang SC / Hiragino / 宋体）。仅限本机渲染演示；商用交付时提醒用户确认字体授权，免费可商用的选择有思源黑体、思源宋体、阿里巴巴普惠体。
