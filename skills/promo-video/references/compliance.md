# 演示阶段的合规底线

当前为演示用途，完整的法律审核留到正式上线前。以下是每支片都要遵守的最低要求：

1. **声明**：没有用户提供的 Logo、品牌授权或真实数据时，`brand.disclaimer` 必须写明，例如「示例品牌与数据，仅用于演示，与任何真实企业无关」。它显示在片尾底部。
2. **不编造事实**：数据、客户名、奖项、认证只用用户素材里明确给出的。
3. **绝对化用语**：避免「最」「第一」「唯一」「国家级」「100%」等（《广告法》第九条），改成可证实的具体描述。
4. **行业红线**：
   - 医疗健康：不宣称疗效、治愈率，不用患者前后对比。
   - 金融：不承诺收益或保本，涉及理财时加风险提示。
   - 教育：不承诺提分、通过率、升学率。
   - 地产：不承诺升值或投资回报。
5. **地图**（2026-10-02，某新茶饮品牌片）：面向中国大陆投放的片子不画世界 / 中国地图——点阵世界地图、简化轮廓都可能漏台湾、南海诸岛，属「问题地图」，正式发布需审图。要表达「全球」就用不带陆地轮廓的涂鸦地球 / 图标 + 城市名卡片。
6. **素材授权**：第三方 Logo、截图中的他人内容、字体、音乐都需要可追溯的授权；交付说明里列出配乐与字体来源。
