# 设计原则：Apple 式精致 + 大师视角 + 导演运镜

所有宣传片默认按本文执行。它回答「怎样才算做完」：每一帧都经得起暂停截图，每一次运动都有理由，每一个声音都落在动作上。

## 1. Apple 式设计语言

- **一屏一个想法。** 一个画面只讲一件事，最多一行主标题 + 一行副标题。信息多就拆成多拍，不堆在同一屏。
- **字体有性格。** 字体按 [typography.md](typography.md) 选：调性 → 配对 → 提案图给用户选；一个有性格的标题字 + 一个退后的正文字，真斜体、无伪粗体、带 opsz 的字确认轴在。不要默认落到 DM Sans / SF Pro / 苹方。
- **大字、少字、紧字距。** 主标题 90–130 px（1080p），字重 700–800，字距 −0.02 到 −0.03 em；副标题 28–34 px，字重 400–500，透明度 0.6–0.75。中文标题不加负字距。
- **留白是主角。** 主体占画面 40–60%，四周安全边距 ≥ 90 px。宁可把字缩小，也不贴边。
- **克制用色。** 一个品牌主色 + 中性黑白灰；强调色只给一个词、一个按钮或一个数据，全屏同时出现的强调元素不超过两处。
- **材质可信。** 用真实的光影区分层级：柔和大投影（blur 60–120 px、透明度 0.35–0.6）、1 px 半透明描边、毛玻璃（backdrop blur 12–16 px）、顶部高光。不用粗描边、纯色硬阴影；渐变文字只在品牌官网自己用渐变字时使用，且只给一个关键词。
- **产品是英雄。** 真实界面、真实素材、真实数据居中放大；装饰元素（粒子、网格、光斑）透明度 ≤ 0.2，只做氛围。粒子高潮、满屏翻色这类「表现档」手艺按 motion-craft.md 的档位规则放开，但每帧仍只有一个焦点。
- **像素级对齐。** 同组元素共用基线和左边线；圆角体系统一（卡片 14–22 px、按钮全圆角、图标底板 22.37%）；数字用等宽数字 `fontVariantNumeric: tabular-nums`。

## 2. 图标

- **只用成套矢量图标**：`lucide-react`（ISC，可商用），全片统一 `strokeWidth={1.75}`、圆角端点。禁止占位方框、混用不同图标库。
- **需要图标自己动时用 lucide-animated**（同一套线条，MIT，467 个）：`<AnimatedIcon>` 或 `<IconTile anim=… playAt=…>`，只在接触帧播一次，见 [animated-icons.md](animated-icons.md)。
- **emoji 只用 Google Noto**（动态 Lottie 或静态 SVG，`<NotoEmoji>`），不用系统 Apple emoji 字体（版权灰色）。默认仍不用 emoji；课程、社媒、轻松向的片子或用户要求时才用。
- **语义精确**：先想「这个动作/对象在 macOS 或 iOS 里用什么符号」，再在 Lucide 里找最接近的（商机 `Radar`、方案 `DraftingCompass`、报价 `BadgeDollarSign`、合同 `FileSignature`、超分 `MonitorUp`、重拍 `SwitchCamera`）。用 `node -e "require('lucide-react').Name"` 确认名称存在。
- **尺寸有层级**：界面内 18–22 px（跟随字号）；功能节点用 `IconTile`（应用图标底板：连续圆角、品牌渐变、顶部高光、同色柔光，图标占 46%）；同一画面只用一种尺寸档。
- **状态有过渡**：未激活是玻璃态低透明度，激活时 `IconTile on` 从 0 到 1 点亮并带 `E.back` 回弹，不要瞬间切换颜色。

## 3. 大师视角

动手前先回答三个问题，写进分镜的「画面」列：

1. **观众第一眼看哪里？** 每帧只有一个视觉焦点，用大小、亮度、景深和运动引导到它，其余元素退后（模糊、变暗、缩小）。
2. **这一拍的情绪是什么？** 惊叹（大场面、慢推）、理解（界面特写、静稳）、兴奋（快切、按拍）、信任（数据、真实素材）。情绪决定运镜和节奏，不是反过来。
3. **删掉它会损失什么？** 损失不了就删。每段只保留一个主动作和一个细节动作（见 cinematic.md「动效规则」）。

构图：主体放三分线或绝对居中（对称构图用于品牌时刻和收尾）；文字与主体分区不重叠；横向运动给前进方向留空间；人物与产品的视线、朝向指向画内。

## 4. 导演运镜

每个镜头的运动必须有动机：跟随动作、揭示信息或表达情绪。落地方式：

| 手法 | 出处 | 用在哪 | 实现 |
|---|---|---|---|
| 精确的推轨 | 大卫·芬奇 | 界面演示跟随光标与输入 | `track()` 关键帧，运动在动作开始前 4–6 帧起步，到位后静止 |
| 缓慢推近 | 苹果发布会、库布里克 | 标题、品牌时刻 | 整段 3–8% 缩放，`E.sine` 或 `E.out` |
| 环绕揭示 | 产品广告 | 3D Logo、体素头像、产品 | 相机绕 Y 轴 15–50°，配合光扫 |
| 穿越转场 | 诺兰、MV | 开场进入正片 | 镜头穿过 Logo 或物体中心，`E.in2` 加速 |
| 焦点转移 | 罗杰·狄金斯 | 多个对象依次登场 | `DepthOfField` 焦距跟随当前对象；DOM 场景对非焦点加 4–10 px blur |
| 甩镜切 | 埃德加·赖特 | 同场景换机位、快节奏 | 6 帧横移 + 运动模糊，落在节拍上 |
| 猛推收尾 | 预告片 | 段落结束接下一段 | 最后 10–14 帧放大 2–4 倍，`CameraMotionBlur` |
| 锁定机位 | 韦斯·安德森 | 数据、对比、CTA | 不动，靠元素自身动画 |

规则：
- 运动曲线全部用 `motion.ts` 的缓动，禁止线性位移（线性只用于透明度淡入淡出）。
- 同一镜头只做一种主运动；相邻镜头方向交替；CTA 与数据画面保持静稳。
- 镜头切在动作上（按下按钮、元素落地、节拍重音），声音比画面早 1–2 帧进入（J-cut）更自然。
- 速度有呼吸：快切段（2 拍一切）之后接一段 4–6 秒的静稳演示，再进入下一轮高能。
- **切点连续**：出现 / 消失 / 参数切换都是帧号的连续函数，转折处留一个承载物贯穿前后，新内容从它里面长出来；不在同一帧卸掉旧场景换新场景，不用 `expo.in` 缓动冲向切点（detail-pass.md）。硬切可以，但必须是有意的，并写在分镜的「转场」列里。

## 5. 声音

- 每个可见动作配一个声音，声音落在动作的接触帧（点击按下、卡片落地、数字砸下），不是动作开始帧。
- 重复音效轮换变体（`key-1..8`、`slam-1..3`、`swish-1..3`），同一音效连续不超过 3 次。
- 全片只有两处最响：开场落点和收尾落点；其他音效让位给配乐。成片 −14 LUFS、编码后 true peak ≤ −1 dBTP（`rn finish` 保证，`rn qa` 检查）。
- **声音永远不落数字静音**：转折处用低通扫频 + 淡出关掉音乐，最后半秒送进混响做尾音，新的低频床从尾音里渐入；硬停要有自然衰减。用 `rn qa` 查 `dead_air`、`level_jumps` 和 `clicks`。

## 6. 交付前的大师审片

逐段抽 2–3 帧（动作中段 + 定格）打开图片查看，并逐条确认：

- [ ] 暂停任意一帧都能当海报：无溢出、无截断、无文字压主体、四边留白足够
- [ ] 每帧只有一个焦点；强调色不超过两处
- [ ] 图标全部来自同一图标库、同一线宽；没有 emoji 和占位图形
- [ ] 字体：提案选定、写在选型卡里；没有系统回落字体和伪粗体 / 伪斜体；中日文无负字距；授权记录在 `public/fonts/LICENSES.md`（typography.md §11）
- [ ] 界面还原的布局、文案、配色与官网一致；数据和模型名都有出处
- [ ] 运动有动机、到位后静止；没有线性位移、没有无意义的漂移
- [ ] 切点落在节拍或动作上；段落之间有快慢呼吸
- [ ] 每段有一个主手艺，段落接缝有设计过的转场（至少三种、硬切不超过一半），开场物件在结尾回来（motion-craft.md）
- [ ] 配乐来自曲库或用户、和最近几支片不重复；主段落落在 Logo 或第一个大转场上，切点按曲子 BPM 对齐
- [ ] 每个动作有声音；响度检查通过
- [ ] 最后一帧（CTA）静稳、清晰，停留 ≥ 2 秒
- [ ] 切换点：列过「挂载 / 卸载 / 参数切换」清单，前后各 4 帧看过（`rn sheet --around … --span 4`），`rn cuts` 列出的硬切都是有意的，没有无意的黑帧
- [ ] 声音：`rn qa` 的 `dead_air` / `level_jumps` / `clicks` 为 PASS；有意的写进了 `qa-accept.txt` 和交付说明
- [ ] 文字：`typo_lint.py` 和 `font_check.py` 通过；文字不与物体相撞，无孤字、无悬挂分隔符
- [ ] 交付文件是 `rn finish` 的输出，`rn qa` 没有 FAIL（固定帧率标记、BT.709、moov 前置、音画等长、响度与 true peak）；4K 片附 1080p

任何一条不满足就修，修完重新抽帧，再渲染成片。

> 细节审片的流程、脚本和阈值见 [detail-pass.md](detail-pass.md)；字体与排版细节（光学字号、字重 / 字距 / 行高、真标点、手工断行）见 [typography.md](typography.md)。
