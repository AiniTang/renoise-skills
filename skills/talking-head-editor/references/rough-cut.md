# 转写与粗剪

## 转写

```bash
python scripts/transcribe.py 口播1.mov 口播2.mov -o transcript.json --prompt "Claude Code、Codex、vibe coding"
```

脚本先用静音检测把素材切成一个个「语音岛」（连续说话的片段），再逐岛识别。输出里每个岛有起止时间、文字、逐字时间；`suspect: true` 的岛是疑似识别失败或幻觉，人工看一眼。

识别后端会自动选：本机有 whisper.cpp 和模型就用它（快），否则用 faster-whisper 或 openai-whisper。没有任何识别环境时，可以在 Renoise 云端沙箱里跑（沙箱自带 faster-whisper）。

## 判断留哪些岛

先让脚本起草：

```bash
python scripts/auto_edl.py transcript.json -o edl.json --breath premium_breath
```

它按下表自动删重录（后面 3 个岛以内有一句开头相同、相似度超过 0.8，只留最后一遍）、说了半句停下的、只有语气词的、疑似幻觉的，岛开头结尾的语气词按逐字时间剪掉；删掉的写在 edl 的 `dropped` 里并打印原因。你再读一遍 transcript.json 和 dropped，按下表把它判错的改回来，然后改文字。

| 情况 | 怎么认出来 | 处理 |
|---|---|---|
| 重录 | 相邻几个岛开头相同或意思相同 | 只留最后一遍（通常最顺），除非前一遍明显更好 |
| 说了半句停下 | 岛很短、句子不完整，紧跟着一个更完整的版本 | 删 |
| 口误、口头禅 | 「呃」「那个」「就是说」、说错又更正 | 删掉口误部分；一个岛里有口误可以拆成两段只留对的 |
| 自言自语 | 「再来一遍」「刚才说错了」「这段不要」 | 删 |
| 气口 | 岛与岛之间的停顿 | 由 pad 统一处理，不用单独管 |
| 内容重复 | 前面讲过的观点又讲一遍 | 留更精炼的那遍 |
| 疑似幻觉 | suspect 标记、内容和上下文无关 | 删 |

拿不准的重录（两遍都完整、各有好坏），告诉用户你选了哪遍、为什么。

## 写 edl.json

```json
{
  "canvas": {"w": 1080, "h": 1920, "fps": 30},
  "speed": 1.05,
  "pad": [0.06, 0.12],
  "clips": [
    {"src": "口播01.mov", "t0": 1.05, "t1": 9.33, "text": "Vibe coding 一年半以来，我踩了无数的坑。"},
    {"src": "口播02.mov", "t0": 2.05, "t1": 6.43, "text": "第一，让 AI 加新功能，它不仅没写对，还把之前的功能改坏了。"}
  ]
}
```

- `t0`、`t1` 用转写里岛的时间；只留岛的一部分时，用该部分第一个和最后一个字的时间。
- `text` 写正确的文字：改掉识别错字、加上标点，但不改用户的说法。字幕和逐字时间都从这里来。
- `speed`：整体提速让语速更紧凑，真人 1.05~1.09 听不出变调，超过 1.1 听得出来（脚本会提醒）；语速本来就快的人保持 1.0。AI 配音的素材写 `"ai_voice": true`，可以提到 1.2。
- `breath`：气口档，按风格选（rough_cut_breath_trim）：
  - `premium_breath` 高级感留气口（默认）：句间留约 0.3 秒，一句里超过 0.6 秒的停顿收成 0.35 秒；段落结尾那一句写 `"para": true`，那里再多留 1 秒，给章节页、定格、反应镜头用。段落留白只在那一秒画面上有东西接得住时才加（章节页、定格、反应镜头）；60 秒以内的短片、宣传片不加，句子之间直接接上，留白会被当成没剪干净的气口。
  - `web_tight` 网感紧剪：句间只留约 0.08 秒，一句里超过 0.15 秒的停顿也收成 0.08 秒，口播在这里会跳一下，这就是网感「一句里也切」的样子；渲染时自动在这些刀口跳景别遮住跳剪。
- `pad`：可选，写了就不用气口档的句首句尾余量（`[前, 后]` 秒），吞字就加大。同一素材里前后紧挨的两段（一个岛拆成两段时），余量在中间对半分，不会把同一段声音播两遍。
- 顺序可以调整：开场钩子经常把最有冲击力的一句（结果、结论）提到最前面。

## 粗剪

```bash
python scripts/rough_cut.py edl.json -t transcript.json -o .
python scripts/init_timeline.py . --style premium
```

得到 `aroll.mp4`（已裁成画布尺寸）、`lines.json`（每句话在新时间线上的时间和逐字时间）和 `timeline.json` 骨架（含自动断好的字幕）。

粗剪后听一遍（或让用户听），检查有没有剪掉半个字、两段之间语气不连贯、气口太紧喘不过气。

## 节奏参考

| 指标 | 参考值 |
|---|---|
| 平均几秒一刀 | 2 秒左右（知识口播），观点类可以 3~4 秒 |
| 字幕每秒字数 | 6.5~7.5 字 |
| 粗剪后时长 | 一般是原始素材的 50%~70% |
| 句间气口 | 网感紧剪 0.05~0.1 秒；高级感 0.2~0.4 秒，段落之间 1~4 秒设计留白，气口和留白合计约占 5% |

粗剪完脚本会打印几刀、平均几秒一刀、停顿占多少。实测「6 个坑」口播 02：原片 41.7 秒，网感紧剪 18.2 秒、平均 2.6 秒一刀；高级感留气口 20.6 秒。

声音先入（下一句先响、画面后切）不在粗剪做：单机位口播两句之间声音先进来时，画面上人嘴没动，口型会穿帮。它在包装阶段自动做，只用在素材或章节页盖住画面的地方，见 audio.md「声音参与转场」。
