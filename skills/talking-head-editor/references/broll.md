# 补齐 B-roll

大多数用户只拍了 A-roll（自己对着镜头说话）。B-roll 不够，再好的包装也撑不起高级感。按下面的优先级逐句补齐，每条 B-roll 记下来源，方便最后在简介里注明。

## 优先级与来源

| 顺序 | 来源 | 为什么排这里 | 怎么做 |
|---|---|---|---|
| 1 | 用户自己的截图、录屏、照片 | 最真实、最可信，观众最买账 | 方案里列出「需要你补的素材」，说清楚截什么、录什么、多长 |
| 2 | 代码做的图形动画 | 不花钱、可精确控制、风格统一 | `make_graphic.py`（数字、柱状图、对比、步骤、时间轴、金句）；复杂的用 HTML 或 Manim |
| 3 | 公开可商用素材库 | 真实拍摄的空镜，质量高 | `broll_search.py`，需要 Pexels 或 Pixabay 的免费 API Key |
| 4 | Renoise MCP 生成 | 搜不到、拍不了、要定制的画面 | 先报价、等用户确认，再生成 |

还有一个零成本来源：**口播素材本身**。同一段口播可以做成虚化背景（aside）、圆形头像（pip）、推近特写，这些都不需要新素材。

## 1. 向用户要素材

最值钱的 B-roll 是用户手里已经有的东西。plan.md 里写清楚：

- 截图：说到的网页、聊天记录、后台数据、评论区、成绩单、订单。截图要原图，别截压缩过的。
- 录屏：操作演示，竖屏录或横屏都行（横屏会用双层构图），录完整过程，等待的部分剪辑时加速。
- 照片：背书用的生活照、证书、作品。

## 2. 代码做图形

`make_graphic.py spec.json -o broll/xx.mov --style premium` 生成带透明底的动画：

| 模板 | 用在 |
|---|---|
| number | 一个关键数字（估值、增长率、用户数） |
| bars | 几个数字的比较（排名、份额） |
| compare | 两样东西的对比 |
| steps | 步骤、清单 |
| timeline | 历史、发展过程 |
| quote | 金句、原话引用 |

模板不够用时，自己写：
- **HTML 动画**：写一个网页动画，用 Playwright 逐帧截图或录屏转成视频（Renoise 沙箱自带 Playwright 和无头 Chromium）。适合排版复杂的信息卡片、网页效果。
- **Manim**：数学公式、坐标图、几何讲解（Renoise 沙箱有 `manimgx`）。
- **Blender**：3D 物体旋转展示（沙箱可用 `bpy-python`）。

图形的风格要和全片一致：同一套字体、同一个强调色、同样的圆角。

## 3. 公开素材库

```bash
export PEXELS_API_KEY=...      # https://www.pexels.com/api/ 免费注册
export PIXABAY_API_KEY=...     # https://pixabay.com/api/docs/ 免费注册
python scripts/broll_search.py "rocket launch" --kind video --orientation portrait -n 6
python scripts/broll_search.py "rocket launch" --kind video --pick 0 3 -o broll/
```

- 用英文关键词搜，具体的名词加动作（"rocket launch night"、"woman typing laptop close up"）比抽象词（"success"）好得多。
- 先列候选看预览图，选中再下载；竖屏优先，横屏素材用 `fit: double`。
- 没有 Key 时：告诉用户注册只要一两分钟，或者直接改用 Renoise 生成。

**版权边界**：只用明确可商用的库。不用影视剧、综艺、别人的短视频片段，哪怕只截几秒。新闻截图可以作为评论引用，注明来源，不要大段搬运原文。

## 4. Renoise MCP 生成

### 什么时候用

- 具体画面在素材库搜不到（比如「中国火箭在海上回收」）；
- 抽象概念要视觉化（「天地一张网」「数据在流动」）；
- 需要和人设统一的定制画面；
- 一两秒做不出来的小动画：取一帧静图，让模型生成后续动态（例如爆炸、翻页、展开）。

### 模型默认值

| 要什么 | 默认模型 | 说明 |
|---|---|---|
| 视频 B-roll | Wan 3.0 | 便宜，2~30 秒，最高 1080P。只有用户点名才用 Seedance 2.5（贵） |
| 写实图片 | Seedream 5.0 Pro | 照片质感的场景、物体 |
| 带文字的信息图、海报 | GPT Image 2.5 | 文字渲染准确 |

配乐和音效不用 Renoise 生成，从免版权曲库下载，见 `audio.md`。

生成前先 `load_skill model-routing` 确认，用 `list_models` 看最新参数。

### 流程

1. 把要生成的 B-roll 列成清单：每条写用途（哪句话）、画面描述、时长、比例（竖屏 9:16）。
2. 调 `estimate_cost` 报总价，同时调 `get_account` 看余额，在对话里告诉用户「生成这 N 段共需 X 积分，你现在有 Y 积分，要生成吗」。
3. **等用户在对话里明确同意**再 `create_tasks`；工具弹窗里的自动批准不算用户同意。
4. `wait_tasks` 等完成，`download_results` 下载到项目的 `broll/`。

### 写提示词的要点

- 一条 B-roll 只表达一件事，写清主体、动作、镜头运动、光线、风格，例如：「竖屏，夜晚海面上的火箭垂直降落回收，尾焰照亮海面，镜头缓慢推近，写实纪录片质感，无文字」。
- 明确写「无文字、无水印、无人脸特写」，避免和字幕打架、避免出现陌生人脸。
- B-roll 不需要声音，生成时关掉音频（模型支持的话）。
- 和全片色调一致：高级感偏冷静、低饱和；综艺感可以明亮。

## 处理规则（放进时间线时）

- 横版素材统一用双层构图（`fit: double`）：下层铺满虚化压暗，上层裁成 4:3 或 1:1，全片固定在同一高度。
- 截图统一做成卡片（`fit: card`）：圆角、投影，配 `aside` 版式。
- 静态画面要动：图片 `motion: push`，卡片 `motion: rise`。
- 录屏：等待段 `speed` 2~10 倍，要看细节的地方用 `focus` 局部放大。
- 每条 B-roll 停留 1.5~4 秒，切点对齐句子开头。
