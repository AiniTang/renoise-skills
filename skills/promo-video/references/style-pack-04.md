# 风格扩展包 04：十四行诗 · 3D 景深（"诗 + 证据"的发布片）

> 状态：已用于一支 AI 模型发布概念片（50s，2026-09-29）；完整示例工程未随公开版发布，下文是可复用的手法与踩坑。口碑记录见 style-router.md。

由来：官方发布片（@claudeai 的 Opus 5.5 / Sonnet 5.5 推文视频）是纯品牌诗——策展式真实影像 + 白色衬线小字 "There's more to discover."，**一个功能、一个数字都不演**；能力和对手对比全在推文串文字里。这个包补的是另一半：**同样克制的诗性外壳，但每一行诗都对应一个可验证的能力**。

## 什么时候用

- 适合：模型/产品发布片、品牌片要"既有质感又要证明实力"；产品**名字本身能做文字游戏**（Sonnet=十四行诗、Opus=作品）；有官方数量级事实（680,000 行、30% 更快、40% 更省）可以做成可数的视觉。
- 不适合：要逐条讲功能的讲解片；没有可引用的官方事实（这个包靠"数字署名"立住）；用户要真人镜头。

## 十二条精髓（按重要性）

1. **形式即概念**：剧本本身就是一首诗（莎士比亚体 ABAB CDCD EFEF GG，抑扬四音步）。一行一小节：80 BPM、每行 3.0s = 90 帧，14 行 = 42s，前面 2.4s 静场，后面 5.6s 落款。第 9 行是"转折"，也是全片换挡点。角落计数器 `05 / 14 · C`（行号 + 韵脚字母）让观众自己发现这是首十四行诗。
2. **平面 → 立体，用镜头讲区别**：开场是长焦（fov 10°）看一面纸墙上的"聊天窗"，一切都像平的（"答案世界"）；圆洞从空的虚线框（"没有成品"）里豁开，**滑动变焦**（相机推进 + fov 10→40）冲进 3D 工坊。不点名任何对手，区别在形式里。
3. **证据层 = 规格书 HUD**：左上角等宽小字，只引用官方页面/推文的原话并署名（`680,000-LINE MIGRATION IN LESS THAN A DAY — REPORTED BY AN EARLY TESTER, CLIO`）。唯一提到对手的一句是官方原文 "often beating other models running at their highest settings"，照引。不编数据，片尾写 Unofficial + 出处。
4. **一个可数的奇观**：`680,000` 根笔画 = 680,000 行。GPU 实例化 `InstancedBufferGeometry`（每根 13 个 float：混沌位置、有序位置、混沌方向、方位角/随机数、所属光线方向），顶点着色器里做形态插值。**一根笔画都不多、不少**，HUD 计数 = `680000 × 扫描进度`。
5. **扫描 = 一天**：一根"时针"绕圆盘一周，越转越快、落在整拍上（`p^1.7`）。前沿的笔画发白热光；配乐里的滴答也按同一函数反算时间点，越来越密。
6. **"aligns" 的双关落成画面**：混沌的青灰笔画对齐成十二道等宽圆头光线（Claude 星形），圆盘像旭日一样立起来（绕 X 转 −90°→0°）。对齐才出现的各向异性高光（Kajiya-Kay）让"对齐"是可见的。
7. **暗 → 金 → 奶白**：暗场加法混合（笔画发光）→ 黎明地平线光带 → 白天。**白天必须换成普通混合的赤陶色笔画**（双材质，共用同一份几何，交叉淡入），否则加法混合在浅底上会消失。天空过渡走"深夜→琥珀→奶白"三段，不要直接 lerp（会经过灰色）。
8. **诗词排版**：Newsreader（衬线，可变字重）逐词升起 + 模糊，左下；背景衬底用**跟随明暗连续渐变**的 scrim，不要用阈值切换。
9. **配乐**：Lyria 不会严格遵守复杂时间轴。做法：多生成几版，选一版，用 `rn listen`（BPM、拍点、起音）+ 色度分析找到小节线与调性，**按小节重排**（本例：小节 2–9 连续，末 1.4s 低通+淡出「关灯」→ 最后半秒送进暗房混响做尾音 → 自己合成的低频暗段从尾音里渐入 → 小节 11–14 连续 → 终止和弦；不要硬停到静音），高潮的重击自己用合成器补。响度由 `render.sh` 的 `rn finish` 统一处理。
10. **对句用弹的，不用念**：耳语式 TTS 读诗句会显得怪（用户反馈）。改成排版驱动的声音设计：对句每个词每 0.5s 浮现一个，词落下的瞬间落一个玻璃钢琴音（E 大调五声音阶），两行的韵脚词落在**同一个音**上，让韵脚听得见；字标出现给一个温暖的和弦（`tools/build_words.py`）。
11. **事实核查流程**：WebFetch 官方页面 → 再用浏览器看官方推文视频（见下「读官方视频」）→ 只用能追溯到原文的数字。
12. **转折处不许硬切，也不许出现数字静音**（用户反馈过，通用配方已提到 [detail-pass.md](detail-pass.md)）：片中最容易出事的是"明→暗"那一刀（第 9 行）。做法：① 灯光在约 1s 内熄灭（`darkAt` 用 smoothstep，764→796），天空经"琥珀"而不是灰过渡到夜色；② 最后一个句点（火花落成的圆点）**保持发亮**并让它的光晕在熄灯时点燃，当画面全黑后才卸载车间；③ 云团从这个点里"长出来"——着色器里加一个揭示半径 `uRev`（球内笔画才存在，边缘 `4·rv·(1−rv)` 的琥珀色余烬光），半径 = max(小气泡, 相机距离 − 3)，相机后拉时墨迹永远在相机前方 3 个单位，杜绝近景"火柴棍"乱象；④ 声音同理：音乐用低通扫频 + 淡出"关灯"，最后半秒送进暗房混响做尾音，暗底 drone 从尾音里**渐入**（1.8s），心跳第一下落在圆点点燃那帧，整段不低于约 −35 dB。

## 技术坑（都踩过）

- **深度打架**：卡片正面（画布纹理）与板厚前表面共面，远距离出现三角碎片。修法：`polygonOffset` + 面板前移 0.004 + 相机近裁面随距离变（`near = (dist − 0.8) × 0.12`）。
- **透明物体在景深里被糊掉**：不写深度的物体会被 DOF 当成"无限远"。给笔画 `depthWrite: true`，片元 alpha < 0.07 直接 `discard`。
- **颜色被转换两次**：three 新版 `Color.set('#hex')` 已经 sRGB→线性；再调 `convertSRGBToLinear()` 会让奶白变黄褐、黎明变火红。
- **字体先于绘制**：画布文字在字体加载前算的布局（宽度）会偏窄。`useFonts()` 返回 `ready`，未就绪不渲染 3D，布局缓存只在 `document.fonts.check(...)` 通过后写入。
- **NaN 法线**：倒角面退化会产生 NaN，泛光把整帧抹成黑。挤出几何后 `sanitize()`，后处理链第一个放 `NanGuard`。
- **标签跟 3D 走**：DOM 标签用 `Vector3.project(camera)` 定位，**要把 `setViewOffset` 的画面偏移加回去**（`x += shift × 1920`）。
- **路径要分段**：Catmull-Rom 会把矩形轮廓拉成圆团。轮廓用直线段单独一段，其余用曲线；墨线只留 1.5s 彗尾（顶点 alpha 渐隐），不累积。
- **切换点全是坑**：凡是"某物在第 n 帧挂载/卸载"或"后期参数在第 n 帧切换"的地方（天空球、车间、泛光、暗角、景深范围、雾），前后 3 帧都要截图看。让它们都是帧的连续函数（`bl = clamp01((darkAt−0.45)/0.55)` 之类），天空球从熄灯开始就存在且颜色 = 场景背景色。
- **加法混合的光晕被面板盖住**：`Panel3D` 的面是 `transparent` 且 `renderOrder=2`，光晕精灵默认 0 会先画、被面板盖掉，直到面板卸载才"突然出现"。精灵设 `renderOrder={3}`。
- **expo 缓动别用于切前的推近**：`E.in`（expo.in）会把整段位移挤在最后几帧，看起来像"撞"上去。用 sine / 二次 inOut，并让镜头在到达时已减速。
- **句子要在句点落下前打完**：打字进度用 `E.out` 会渐近，最后一个字母比句点还晚。改成线性 + `ceil`，比句点提前约 4 帧完成。
- **配乐永远不要硬停到数字零**：用 `fft_conv` 做暗房混响尾音（Lyria 下一小节的第一拍是满幅重击，不能拿来延长），并检查混音里最安静的 50 ms 与最大的采样跳变（`build_score.py` 末尾会打印）。

## 读官方视频（浏览器）

X 的视频层不会出现在截图里。做法：`/status/<id>/video/1` 打开灯箱 → 在页面里执行脚本找最大的 `<video>` → `pause()` + 设 `currentTime` 等 `seeked` → 把帧 `drawImage` 到一张固定在页面顶层的 `<canvas>` → 再截图。逐秒抓帧，不下载文件。
