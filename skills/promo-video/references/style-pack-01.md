# 风格扩展包 01：音乐驱动 · 液态融合 · 数据叙事 · 无限穿越 · 透视揭示

五个模块，都在 `templates/remotion/src/cinematic/`，全部由帧号推导（无 CSS 动画、无 Web Audio、无随机数），可直接在电影级 Film 里组合使用。

灵感来自 awesome-opus5-5-videos 里的社区作品（见 [inspiration-sources.md](inspiration-sources.md)）。只借鉴手法，代码全部自写；不要把别人的提示词原文搬进片子或文档。

## 什么时候用哪个

| 模块 | 适合 | 放在片中哪里 | 不适合 |
|---|---|---|---|
| 音乐驱动 `AudioReactive` | 所有快剪片、发布片、音乐/音频产品 | 个别关键拍：Logo 落地、章节翻转、高潮时用 `HitCam` 推一下；频谱只做画面里的元素（声波条、字母律动） | 讲解片、旁白主导的片子；**任何时候都不要整段包 `BeatCam`**（每个鼓点都抖＝背景在晃） |
| 液态融合 `Liquid` | 「多合一」「融合」「整合」类卖点，Logo 变形，转场 | 多个能力融成一个产品；段落之间用液态擦除 | 精密 UI 演示段（滤镜会把细节熔掉） |
| 数据叙事 `DataStory` | SaaS 增长、融资、对比、年度报告 | 证明段：排名赛跑、趋势线、占比环 | 没有真实数据时（必须标「演示数据」，否则别用） |
| 无限穿越 `InfiniteZoom` | 品牌形象片、作品集、多模型/多场景展示 | 开场或模型墙：一镜到底穿过 4–6 个画面 | 素材里找不到可以「钻进去」的物体时 |
| 透视揭示 `XRayReveal` | 硬件、App、网站、技术架构 | 卖点段：光标划过，露出内部结构、代码、参数 | 素材只有抽象插画、没有可拆解的结构 |

## 1. 音乐驱动 AudioReactive

先把配乐算成逐帧特征（每次换曲都要重跑）：

```bash
python3 <skill>/scripts/audio_features.py <项目>/public/music/bgm.wav
```

输出 `public/music/features.json`：`bass/mid/high/level` 每帧 0–1，`onsets` 鼓点帧号，`spec` 每帧 24 个对数频段。

```tsx
<AudioProvider>              // 根部包一次，内部 delayRender（放在组件里，并行渲染不会超时）
  <HitCam f={F} hits={[logoAt, chapterAt, climaxAt]}>…</HitCam> // 只在列出的 3–4 个关键帧推一下，其余时间机位锁定
</AudioProvider>
const d = useAudio(); band(d, "bass", F); kick(d, F); kickIndex(d, F); specAt(d, F)
```

现成组件：`HitCam`（关键帧推镜，默认用它）、`Spectrum`（bars / mirror / ring）、`BassPulse`、`KickRings`、`ReactiveType`（字母随各自频段拉伸，歌词视频感）。`BeatCam`（每个鼓点都推）与 `KickFlash`（按拍闪光）只留给纯音乐可视化/动效作品集，宣传片不用。

要点：
- `f` 传**整片绝对帧**。在 `<Sequence>` 里要加回偏移（`F = local + at(start)`），否则画面和音乐错位。
- **机位默认锁定。** 用户反馈（2026-09）：连续几支片整段套 `BeatCam`，画面从头抖到尾，"正常的片子怎么可能一直抖"。规则：`HitCam` 每支片 3–5 个关键帧（Logo 落地、章节翻转、数据砸出、结尾定格），抖动 ≤ 6 px、推镜 ≤ 2%；有字要读的镜头不用；按拍闪光整片最多 1–2 次。节奏感靠剪辑点和元素自身的动画卡拍，不靠整个画面晃。
- 剪曲后特征要重算；`onsets` 偶尔会抓到半拍的镲，需要严格按拍时用 BPM 网格 `at(b)`，特征只管「力度」。

## 2. 液态融合 Liquid

```tsx
<Goo id="goo-a" blur={26}>                       // 模糊 + alpha 阈值 → 相碰的形状融成一片
  <Blobs blobs={morphBlobs(layouts.row(5,…), layouts.merge(5,…), t)} screenFill={CHROME} />
</Goo>
<LiquidText p={p} text="ONE API" />               // 液滴凝结成字，结尾自动切清晰字
<LiquidWipe p={p} color="#F2F0EA" />              // 液滴从上方滴落吞没画面，做转场
<LavaField f={f} colors={[…]} />                  // 熔岩灯背景（放进 Goo，透明度 ≤ 0.5）
```

要点：
- 每个 `Goo` 的 `id` 必须唯一；`blur` 约为液滴半径的 0.3–0.5 倍，太大会整片糊掉。
- 滤镜会把 3D 压平：不要放进 `preserve-3d`。
- 金属质感用 `screenFill={CHROME}`，每个液滴取同一张全屏渐变的对应部分，融合后是连续金属面；不要把渐变铺成整层（会盖满画面）。
- 文字不要一直留在滤镜里——`LiquidText` 的最后 28% 会换成清晰字，自己写时也照此处理。
- 熔岩背景在出字时压到 0.2 以下，否则抢字。

## 3. 数据叙事 DataStory

```tsx
<BarRace f={f} rows={[{label, color, values:[…每一步]}]} stepFrames={at(1.7)} stepLabels={["Q1",…]} suffix="万次" />
<LineReveal f={f} dur={at(5)} series={[{points, color, label}]} xLabels={[…]} />
<DonutBuild f={f} slices={[{value, color, label}]} center={(t) => `${Math.round(t)}%`} />
```

要点：
- 排名换位、柱长、最大值都走弹簧，数字跟柱长同步滚动；一步 1.5–2 拍最好看。
- 浅底时传 `text="#0B0B0D"`、`muted="rgba(11,11,13,0.2)"`；折线值标签固定深底白字。
- 只用用户给的或官网公开的数字；示例数据必须在角落标「演示数据」。

## 4. 无限穿越 InfiniteZoom

```tsx
<InfiniteZoom p={f / at(2.6)} levels={[{ node: <Img …/>, portal: { x: 0.685, y: 0.49, k: 0.17, shape: "circle" } }, …]} />
```

- 第 i 层的 `portal` 是第 i+1 层在第 i 层里的位置：中心 `x, y`（0–1）、宽度占比 `k`、形状 `rect | round | circle`。
- 相机绕入口的不动点做指数缩放，所以匀速、无缝；整数进度时下一层正好铺满。`loop` 默认开，最后一层钻回第一层。
- 选图：每张图都要有一个能「钻进去」的物体——镜片、屏幕、招牌、牌匾、鼓面、窗、画框。先给图画 10×10 网格定坐标（`sheet.py` 配网格叠加）。
- 圆形入口放在圆形物体上（镜片、鼓面），圆角入口放在屏幕、招牌上；`k` 取 0.12–0.2，太小会糊。
- 一层 2–3 拍；`ease={(u) => E.inOut(u) * 0.35 + u * 0.65}` 让每层到达时略微停顿。
- `Cutout` 是复古剪报框（白边 + 半调网点），做拼贴风时包在素材外面。

**用 AI 生成的「变焦链」静帧做产品变焦（2026-10-02 某口袋相机发布概念片）**：图生图要「同一画面放大 3× / 再放大 4×」，模型并不守倍数——实测 1× → 1.66× → 41.6×（量同一个特征：灯塔栏杆宽 40 → 64 → 1666 px）。做法：每张图量出同一特征的像素尺寸和锚点（灯笼中心），按**真实相对倍数**嵌套叠放（`S` = 相对倍数，`A` = 锚点，屏幕上每张图的缩放 = 0.5·z/S，锚点对齐），细节图只在中心淡入、羽化边缘；读数显示多少倍，画面就真放大多少倍，不许拿 42× 的图标「12×」。嵌套前把细节图的天空按外圈图的平均色做逐通道增益，否则中心一圈色斑。

**两层「希区柯克变焦」**：主体抠图（`851-labs/background-remover`）+ 去掉主体的背景，背景绕主体脚下的接地点放大 1 → 2.75 并逐渐加模糊（长焦浅景深），主体不动——一个镜头讲清 20mm 与 60mm 的区别。去主体别指望图生图「同图删掉狗」（它会重画整条街）；一点透视的街景可以**自相似填洞**：用整张图绕消失点缩小 1/2.3 的副本填进主体区域，迭代 3 次，残影缩到 1/12（`S1Near.tsx` 与项目里的填洞脚本）。

## 5. 透视揭示 XRayReveal

```tsx
<XRayReveal f={f} outer={<Img src={shot}/>} inner={<Blueprint><Img src={shot}/></Blueprint>}
  path={[[0, 260, 420], [at(3), 520, 380], …]} r={220} callouts={[{ x, y, label, sub }]} />
```

- `inner` 可以是任何「内部视图」：`Blueprint`（把同一张截图变成青色蓝图）、代码、线框、爆炸图、数据面板。两层必须像素对齐。
- 透镜经过标注点附近时，引线和标签自动出现；标注写真实参数（字体、色值、模块名）。
- `r` 可以传函数：收尾时放大到 1400 做「整页透视」转场。
- `mode="scan"` 换成竖线扫描揭示，适合对比「前后」或「外观/结构」。

## 样帧检查

- 音乐驱动：抽鼓点帧和非鼓点帧各一张，确认推镜幅度可接受、字没被频谱环压住。
- 液态：抽融合中间帧（看有没有整片糊掉）和结束帧（字必须清晰）。
- 数据：每一步换位的中间帧（行不能重叠到不可读）。
- 无限穿越：每层的 0.5 进度帧（入口物体和下一层要对齐）。
- 透视：透镜经过每个标注点的帧。
