# 敏感信息检查与打码

口播博主经常在截图、录屏里不小心露出自己或别人的隐私：后台截图里的用户邮箱、订单里的手机号和地址、证件照、开发者工具里的 API 密钥、聊天记录里的真名。一旦发出去就收不回来，所以每条视频都要查一遍。

## 什么时候查

在 B-roll 补齐之后、渲染之前查一次（第 6 步）。用户中途新给素材，再查新素材。

## 怎么查

```bash
uv run --python 3.12 --with rapidocr-onnxruntime --with opencv-python --with pillow \
  python scripts/detect_sensitive.py broll/ aroll.mp4 --transcript transcript.json -o sensitive.json
```

- 图片直接识别；视频每 1 秒抽一帧识别，滚动很快的录屏用 `--every 0.5`。
- 能识别的：邮箱、手机号、座机、身份证号、银行卡号（带校验）、护照号、各家 API 密钥和令牌、二维码、「姓名：」「收件人：」后面的名字、带省市区路号的地址。
- 转写里也会查：口播里念出来的号码、邮箱，以及一长串数字。
- 识别不了的要靠你看：人脸（路人、朋友、孩子）、车牌、门牌、快递单、工牌、电脑桌面上的文件名。看 `contact_sheet.py` 拼图时顺带检查。

## 怎么问用户

**不要擅自打码，也不要擅自不打。** 有些信息是用户故意展示的（自己的公众号二维码、自己公司的官网邮箱）。把发现的都列出来，问一次：

> 我在素材里发现了 4 处可能的隐私信息：
> 1. 「后台截图.png」里有一个用户邮箱 tes***com
> 2. 「订单.png」里有收件人姓名、手机号 138****678、地址
> 3. 「开发者工具录屏.mov」第 1~5 秒露出了 API 密钥 sk-***678（建议一定打码，并去平台作废这个密钥）
> 4. 口播第 0:42 你念了一个手机号
>
> 要我把 1~3 打上马赛克吗？第 4 处建议剪掉那半句或者用「哔」声盖住。

报告里只写打了码的预览（前 3 位 + 后 3 位），不要在对话里复述完整的敏感信息。

## 怎么打

```bash
python scripts/mask.py --from sensitive.json --ids 0 1 2 --mode pixelate --outdir broll/masked/
```

然后把 timeline.json 里对应素材的 `src` 换成 `masked/` 下的新文件。

| 方式 | 效果 | 适合 |
|---|---|---|
| pixelate 马赛克 | 一看就知道是故意遮的 | 默认，最常见 |
| blur 模糊 | 柔和，不抢画面 | 高级感视频里不重要的背景信息 |
| solid 纯色块 | 最彻底，完全看不到 | 密钥、证件号 |

- 检测框是按抽样帧算的，内容在滚动时会漏，`--pad` 默认外扩 30%；滚动录屏建议加大到 0.6，或者手动 `--box` 遮住整行。
- 打码后抽几帧看一眼确实盖住了。
- 口播里说出来的隐私，画面打不了码：剪掉那几个字，或者在那一段叠一个「哔」声（综艺感常用，配「秘密」之类的表情）。
- 剪映草稿路线：同样用 mask.py 先处理素材再进草稿，比在剪映里逐个加马赛克特效省事，也保证成片和草稿一致。

## 密钥的特殊处理

视频里露出的 API 密钥、令牌，即使打了码也要提醒用户去对应平台**作废并重新生成**：原视频文件、草稿、云端备份里都可能还留着明文。
