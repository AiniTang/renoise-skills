# 风格扩展包 02：一镜到底接力

学自 Fastlane 宣传片（usefastlane.ai，15s）的手法：全片没有一次硬切，**每个画面都由上一个画面里的物体变来**。组件在 `templates/remotion/src/cinematic/relay/`。

## 什么时候用

- 适合：SaaS / AI 工具 / 自动化产品——产品有「输入 → 处理 → 产出 → 持续运行」的链路；有真实界面截图；30s 左右的发布片、课程片、投流片。
- 不适合：没有界面的实体产品（用硬件概念片）；要逐条讲清很多功能的讲解片（接力链会被拉断）；快剪合集（本来就要切）。

## 四条精髓（写分镜时逐条对照）

1. **接力规则**：分镜表每一行写「从哪个物体变来」。输入框 → 标签 → 钻进输入框 → 隧道 → 飞出一张卡 → 卡扇形展开 → 盖章 → 掉进日历 → 通知 → 数字 → 圆形擦除 → 跑道 → 收成 Logo。写不出来源的镜头，就是断点，换掉。
2. **一条贯穿线索 + 一个强调色**：Fastlane 是「快车道」，从第一道红色流光到赛道圈速到红色地光都在讲快。我们选产品名/卖点里的一个意象（例如一个 AI 办公助手用「一句话化成的绿光」），全片只用品牌主色一个强调色，其余黑白。
3. **用产品自己的界面讲功能**：输入框就是产品入口，扇形就是「多种产出」，日历就是「每天自动跑」，通知就是「结果送到」。少用解释性大字，关键词最多 6–8 个字。
4. **克制质感**：暗底 + 毛玻璃实底（背景字不能透进来）+ 强调色边缘光；等宽「// 注释」小字、点阵数字、一个强调词；转场处才开运动模糊；黑 → 白的大反差全片只用一次（CircleWipe）。

## 组件

```tsx
import { Floor, Streak, ChoreWall, GlassBar, ChipBurst, DivePortal, diveP, diveScale, CardTunnel, CascadeFan,
  CalendarDrop, NotifyStack, DotNumber, CircleWipe, LoopTrack, RELAY_GREEN, Grad } from "../cinematic/relay";
```

| 组件 | 做什么 | 关键参数 |
|---|---|---|
| `Floor` / `Streak` | 地面网格；流光冲进来描出下一个物体 | `rect` = 接下来出现的输入框/卡片 |
| `ChoreWall` | 背景流动的琐事卡片墙（痛点） | `words` 换成客户场景 |
| `GlassBar` | 玻璃输入框：占位语 → 打字 → 发送；`dims` 让被拆走的字变暗 | `typeFrom/typeTo` 卡旁白 |
| `ChipBurst` | 句子拆成参数标签飞出 | 每个 `at` = 旁白念到该词的帧 |
| `DivePortal` + `diveP/diveScale` | 钻进物体：物体内的裁切区扩张到全屏，外层同时往物体中心推镜 | `rect` 同 GlassBar |
| `CardTunnel` | 素材贴满两壁的隧道，关键词从深处迎面飞来 | `images`、`words`、`slowAt` |
| `CascadeFan` | 卡片层叠：**新卡在最前，旧卡平滑后退**；可带「已交付」章 | `cards[].at` 卡旁白 |
| `CalendarDrop` | 3D 日历格子随机填满，一张卡掉进「今天」 | `thumbs`、`drop`、`blurAt` |
| `NotifyStack` | 通知从上方落下压住旧的 | `items`、`gap` |
| `DotNumber` | 5×7 点阵数字（非数字字符画成强调色圆点） | `value` |
| `CircleWipe` | 圆形擦除到浅色 | `at` |
| `LoopTrack` | 流程画成闭环跑道，光点跑一圈，标每轮结果 | `labels`、`rounds` |

所有组件只收整片绝对帧 `f`；颜色走 `theme`（默认 `RELAY_GREEN`，换品牌就传自己的 `{ink, accent, accent2, mint, heavy, mono}`）。

## 旁白驱动的时间轴

这类片子通常带旁白（接力链靠旁白串意思）。流程：

1. 写 6–9 句旁白稿，每句对应接力链的一环；列举式句子（「目标、资料、边界、交付物」）最好卡画面。
2. `narrate_mimo.py` 合成：客户给了本人录音就用 `"clone": "ref.wav"` 克隆（几秒即可）；否则预设音色，先让用户试听一句。`--qa` 看回读差异。
3. timings.json 转存 `src/vo.json`，Film 里 `Wd("b3", "资料")` 取「资料」开口那一帧，所有触发点都从旁白取，不手填帧号。
4. 旁白底下配乐压到 0.3，旁白结束后抬到 0.75；加底部字幕（投流静音自动播放）。

## 坑

- 输入框/标签用**深色实底玻璃**，半透明会把背景卡片墙的字透进来。
- 扇形层叠：第一张从隧道飞来的卡也要参与「后退」，否则会一直压在最前；整组 x 起点 −560、步长 240（卡宽 680）时 5 张刚好在画内。
- 跑道路径要比中间大字宽，标签放在路径外侧。
- 克隆音色会有几句音高漂移，交付时说明，并提供「用户自己照稿录」的选项。
- 一镜到底 ≠ 慢：每一环 2–4 秒，转场本身 12–16 帧，靠运动模糊和音效把速度感做出来。
