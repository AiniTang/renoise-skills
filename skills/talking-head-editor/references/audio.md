# 声音

好配乐的检验标准：关掉人声只听配乐、看字幕，情绪也成立。一条音乐铺到底，视频就会显得「平」；配乐没有节奏、听不清，画面再好也像在催眠。

## 人声

- 渲染时自动做一条链（`audiomix.clean_voice`）：先量素材底噪定降噪强度 → 高通去低频嗡声 → 降噪 → 去齿音 → 轻压缩让大小声更平 → 两遍法把响度拉到 -16 LUFS（综艺感 -15），峰值不超过 -1.5 dBFS。两遍法是先量一遍整条的响度、再按量到的值统一拉，不会像实时拉响度那样忽大忽小。剪映默认的 -23 LUFS 手机外放偏小。
- 每一项都能在 `audio.voice` 里关掉（见 timeline.md）。处理结果按素材缓存，改了时间线不用重算。
- 底噪很大（渲染时打印的底噪高于 -45 dB）、有回声的素材，这条链不够，建议在 Renoise 沙箱里用更强的降噪（沙箱有 pedalboard 等工具），或请用户补录。

## 配乐

### 从哪来

配乐的口味因人而异，Agent 挑的配乐用户常常不满意，所以**先请用户给配乐**；用户没有时才从免版权曲库挑候选，做成试听片让用户选定。不用 AI 生成音乐，也不用代码合成的音当配乐。

| 来源 | 说明 |
|---|---|
| 用户提供（首选） | 开工前就问。用户给的是曲名不是文件时，请用户自己下载放进 bgm/，并确认有使用授权（平台商用音乐库、自己买的授权） |
| 剪映曲库里的曲子 | 用户说「用剪映里收藏的某某」时，不要从剪映缓存里导出音频文件：剪映素材许可协议只允许在剪映里使用和编辑，带商用音乐的视频只能发布到剪映、抖音，会员也一样。做法是代码成片先用免版权曲子，同时出剪映草稿，请用户在剪映里把这首曲子加到配乐轨，从剪映导出后发布到抖音 |
| Mixkit |  `python scripts/music_search.py music --genre hip-hop` 列曲子，`--download 2 -o bgm/` 下载。可商用、不用署名，曲风现代。高级感常用 hip-hop、chillout、downtempo、deep-house、future-bass、corporate-music；综艺感常用 funk、dance-pop、indie-pop、breakbeat |
| Incompetech | `python scripts/music_search.py music --source incompetech --feel "Bright, Driving" --bpm 90-120`。每首标了 BPM 和情绪，按节奏挑方便；CC BY 4.0，**必须在视频简介署名**，署名文字在 `bgm/credits.json` |
| Pixabay Music、YouTube 音频库 | 质量好但没有能直接调用的接口，用户自己下载后放进 bgm/ |

挑歌：节奏感优先。口播配乐要鼓点清楚、有推进力，旋律简单、没有人声，不能抢说话。先从两三个曲风各下载几首候选，再打分排序：

```bash
uv run --python 3.12 --with librosa python scripts/music_score.py bgm/候选/*.mp3 -o bgm/scores.json
```

它量出每首的速度、鼓点能量占比、节拍清晰度、鼓点密度和鼓点进来的时间，算出综合分（速度 100~130、鼓重、拍清的分高）。取前三名各配一段同样的画面（含章节页和大字，各自卡好点）拼成试听片发给用户，用户选定后再用。鼓点进来得晚的曲子，`src_in` 不要早于 `drums_in`。

不要用流行歌曲、影视原声，平台会因版权静音或限流。交付时把 `bgm/credits.json` 里要署名的曲子告诉用户。

### 卡点

配乐选好、timeline 的版式和 B-roll 排好后，跑一次：

```bash
uv run --python 3.12 --with librosa python scripts/beats.py bgm/曲子.mp3 -o bgm/曲子.beats.json   # beat_sync 没找到会自动跑
python scripts/beat_sync.py timeline.json
```

它会选配乐的起点，让一个重拍正好落在开场钩子结束、正片进来的那一刻（或 `--anchor` 指定的时间），再把 B-roll、版式切换、大字、推近、音效的开始时间吸到最近的节拍上（最多挪 0.25 秒，字幕不动）。改前的时间线存成 `timeline.before_sync.json`。

卡点之外的节奏手法：
- 章节切换、数字落地放在重拍上，配一个重音或「嗖」。
- 一段 B-roll 里图片轮换，每 1 拍或 2 拍换一张。
- 鼓点进来之前那一小节留给开场钩子，鼓点一进正片开始。

### 按段落情绪铺

先在 timeline 写 `sections`（段落表，见 plan.md），配乐、留白、声音先入都按段落走。用户给了几首曲子就写进 `audio.tracks` 并标情绪，代码按段落情绪分配、选接缝（交叉淡化、嗖一声盖住、留白、硬切），细节见 timeline.md「段落换曲」。用户只给一首时，在同一首里按段落跳到能量高的另一段。一首曲子铺到底，客户会说「有点平」。

| 段落 | 配乐 |
|---|---|
| 开场钩子 | 有冲击力的短乐句或鼓点，3~7 秒后切主配乐 |
| 口播舒缓处 | 节奏略慢、轻的纯音乐 |
| 信息密、B-roll 切得快的段落 | 节奏加快的配乐，和画面速度对上 |
| 大段 B-roll | 有固定节奏、能循环的一段，脚本会自动循环铺满 |
| 幽默、调侃 | 俏皮的短音乐片段，配乐本身就能当转场 |
| 段落收尾、情绪最高处 | 截同一首曲子最强的结尾段接上去把情绪顶到最高，然后突然留白 |
| 长视频（3 分钟以上） | 中间至少换一首防听感疲劳：给两三首曲子标好情绪，同一首连着放满 75 秒后到下一个段落自动换 |

开场提气：开头 7 秒放一段激昂的，7 秒处 0.34 秒淡出接主曲，写 `audio.open_boost`。

想完全手工排时，每段配乐写一条 `audio.bgm`，`t0`、`t1` 对齐段落边界，`src_in` 选曲子里合适的起点（不写就交给 beat_sync 选），`fade_in`、`fade_out` 衔接；手写了好几段就照写的铺。

### 音量

- 渲染时先测每首曲子的响度，统一拉到目标值：高级感 -23 LUFS、综艺感 -21 LUFS（人声 -16）。曲库里每首音量差很多，所以不用固定的 dB。
- 人一说话配乐自动让开（`duck: true`，侧链压缩阈值 -30 dB、压缩比 6），说话时配乐比人声低约 18~22 dB。
- 开头 13 秒配乐高一档（+5 dB），0.9 秒过渡到正文的音量（`audio.bed`，默认开）：开头带气氛，进正文让位给信息。
- 重音（`hit`、`drop` 这类）前 0.2 秒配乐自动压低 6 dB，给重音让出位置。
- `db` 是在目标值上的微调，配乐抢人声就减。
- 人声始终要听得清，配乐也要始终听得见：说话间隙要能清楚听到鼓点。渲染加 `--stems` 后跑 `audio_check.py` 会算出说话时配乐比人声低多少。

## 音效

音效是情绪的放大器，不是背景噪音。只放在这些点上：

| 位置 | 音效 |
|---|---|
| 转场、画面切换 | 嗖、唰 |
| 卡片、文字冒出 | 轻「啵」、弹出声 |
| 关键词、重点句出现 | 轻「叮」 |
| 重点数字落地、段落高点 | 低音鼓、重音 |
| 操作演示 | 鼠标点击、键盘声 |
| 疑问、吐槽、翻车、成功（综艺感） | 见 style-variety.md 音效对照表 |
| 片尾署名 | 收银机「叮」 |

密度：高级感每分钟 3~8 个，综艺感每分钟 10~30 个。

### 音效怎么配：对着画面和口播，而不只是对着出场

音效要跟画面里正在发生的事、跟口播说到的词对上：打字动画配成串打字声，数字滚动配滴答声，说到「清空」配废纸篓声。这一步要理解内容，所以由你在逐句方案里标出来，写进 timeline 的受控字段；什么时候响、响多久、多大声由脚本算。

**标在画面上**：B-roll、overlay、大字都可以写 `sound`。一下的声音在元素出现时响；铺满一段的声音（打字、滴答）铺满元素时长，或用 `dur` 指定：

```json
{"t0": 12.3, "t1": 14.8, "src": "broll/输入框打字.mov", "fit": "contain", "sound": {"type": "typing", "dur": 1.6}}
{"t0": 38.9, "t1": 41.2, "src": "broll/余量往下掉.mov", "sound": {"type": "tick", "dur": 1.4}}
```

**标在口播的词上**：timeline 顶层 `sounds`，按词找到口播说出它的那一刻（用 lines.json 的逐字时间，`after` 指定从第几秒往后找），也可以直接写 `t`：

```json
"sounds": [{"word": "清空", "sound": "trash"}, {"word": "失忆", "sound": "glitch"}, {"t": 33.9, "sound": "fall"}]
```

声音只能从这张清单里选（`kvlib.SOUNDS`，写错名字脚本会报错）：

| 声音 | 用在什么画面 |
|---|---|
| `whoosh` | 快速划过、切换、元素飞入 |
| `whoosh_big` | 大段转场、章节切换 |
| `pop` | 气泡、卡片、标签弹出 |
| `click` | 点按钮、选中 |
| `tap` | 轻轻放下、轻点 |
| `knock` | 木块敲击，强调一个词 |
| `thump` | 东西落地、大字砸下来 |
| `snap` | 快门、截图、定格、快速推近 |
| `hit` | 重击：重点数字、结论落地（全片少用） |
| `drop` | 低音下沉：转折、坏消息 |
| `swell` | 反向镲片：揭晓前的吸气感 |
| `riser` | 上升音：期待、数字往上涨 |
| `bell` | 清脆铃声：关键词、灵感、对了 |
| `ding` | 提示音：消息、完成一步 |
| `typing` | 打字动画、输入框里出字、代码一行行出现 |
| `tick` | 数字滚动、进度条、倒计时、列表滚动 |
| `glitch` | 出错、故障、画面撕裂、AI 失忆 |
| `shimmer` | 闪光、AI 生成、变魔术、高光时刻 |
| `zip_up` | 往上滑、数值变好 |
| `zip_down` | 往下滑、数值变差 |
| `fall` | 往下掉、崩了、额度耗尽 |
| `drip` | 一滴一滴、逐个出现的小元素 |
| `trash` | 清空、删除、扔掉、文件夹被清空 |
| `crumple` | 揉纸、推翻重来 |
| `page` | 翻页、文档、报告 |
| `error` | 报错、答错、翻车（综艺感更常用） |
| `success` | 成功、搞定、通过 |
| `coins` | 钱、付费、省钱 |
| `door` | 开门转场：推开一扇门进入下一段 |

| `mech_wind` | 上发条：准备、蓄力、倒计时开始 |

| `suspense_tap` | 疑惑、悬念：抛出问题等答案 |

| `cheer_shout` | 欢呼吆喝：情绪突变换曲、高光时刻（全片一两次） |
| `bass_hit` | 贝斯单音：包装出现前垫一下低音 |
| `blade_swish` | 利刃划过：切开、斩断、一刀两断 |

还有三个组合声音：`swing` 挥动落定（嗖一声再落一下，人物冲出、元素甩进来）、`shuttle` 穿梭（嗖叠高音闪光）、`rising_ui` 升调串（重点词一个个蹦出，每个高一个音，写 `step` 0、1、2…）。sound 也可以直接写剪映音效原名，比如「综艺叮」「唰」「挥动声」「DUN DUN DUUUUN!!」，按手法库 sfx_event_engine 的对照表（约 110 条）换成上面的名字，认不出的会报错。

标多少：只标「重点画面动效」和「关键词」，高级感大约 10 秒一处；同一种声音 3 秒内只响一次。重音类（`hit`、`drop`、`dun_dun_duun`、`cheer_shout`）每种全片最多两次，超出的自动去掉。提示音类（点击、叮、啵）一句话里最多 3 个，多了观众会觉得像手机通知：自动配的去掉，手写的压低 6 dB；升调串是成串设计的，不算。

**什么时候响**（sfx_event_engine）：音效的起音（波形起来的那一下）对准画面事件开始那一帧，不是动作最大的那一帧，对到最大那一帧会晚 2~6 帧。蓄力类（反向镲 `swell`、上升音 `riser`）反过来，最响处对准事件。earshot 预设里从专业片子量出的提前、延后几十毫秒保留，最多两帧。同一时刻最多叠两个声音（转场的唰加章节页的重音这种），其余只留一个。

**没标的地方自动配**：章节页、效果转场（见 timeline.md 的 transitions）、素材出场（相隔不到 0.6 秒的一串素材算一次，整串一起配，比如开场照片一张张叠上来；从侧面滑入的卡片配嗖）、大字出现，按风格在几种音效之间轮换。缩放、收圆、分屏这几个版式自带推近、拉远、机械开合声。

**密度**：每分钟上限按风格和强度档：克制档 8 个、网感档 14 个、综艺感 25 个；`audio.sfx_density` 可以改成 `sparse` 稀疏（12 个）或 `dense` 密集（30 个）。超出时先保证对着内容的声音、章节页和转场，再按素材出场、大字的顺序往里加。依据：财经知识口播原片每分钟约 6 个、只在画面上出现东西时加，纯口播段没有音效；综艺向剪辑教程的草稿每分钟约 20 个，每个花字都配一声。

**音效从哪来**：装了 earshot（`python scripts/setup_earshot.py install`）就用它的代码音效库，没有版权问题，并按它从专业片子量出的提前量和比配乐高出的 dB 摆放；废纸篓、翻页、报错、成功、硬币这类生活声音从 Mixkit 下载。没装 earshot 时全部用 Mixkit。大字或素材写 `"sfx": false` 不配；整片不要自动配写 `"auto_sfx": false`。卡点挪动画面时，音效跟着走。不要用提示铃、消息提示音这类手机通知声。

### 音效从哪来

- Mixkit 音效库：`python scripts/music_search.py sfx whoosh` 列出，`--download 1 -o sfx/` 下载。常用类别 whoosh、transition、swoosh、impact、boom、bass、pop、click、camera、typing、notification、bell、glitch、rise。可商用、不用署名。渲染时音效按峰值统一音量（高级感 -9 dBFS、综艺感 -6 dBFS），`db` 微调。
- Pixabay Sound Effects：用户自己下载。
- 剪映草稿路线：用户可以在剪映里换成剪映音效库里的同类音效。

## 留白

- 段落之间、包袱之后、重点数字之后，配乐收住 0.5~2 秒，画面给章节页、空镜或停在口播上，停完必须接一个大变化。
- 写法：段落写 `"seam": "gap"`（`gap` 写秒数）；重音收住写 `audio.stops`：数字放大那一帧一声重音鼓，鼓尾配乐跟着收，空约 1 秒硬切进下一段。全片一两次，留白要短而少。

## 声音参与转场

- **声音先入**（`jcut`，默认开）：铺满画面的素材、章节页结束的地方，下一句人声先响 0.35 秒，画面再切回口播；配乐换曲交叉淡化时后一首也早 0.3 秒进来。单机位口播两句之间不做：声音先进来时画面上人嘴没动，口型会穿帮。
- **音效衔接**：段落 `"seam": "whoosh"`，用一个嗖把舒缓配乐切到快节奏配乐。
- **重音转场**：`audio.stops`，见上面留白。
- **情绪提前入场**：包装出现前 0.2~0.5 秒先垫一个 `bass_hit`。

## 检查

你听不了成片，用数字和图核对：

```bash
python scripts/render.py timeline.json -o out/final.mp4 --stems     # 另存人声、配乐、音效三条分轨
python scripts/audio_check.py timeline.json out/final.mp4
```

它报：成片和人声的响度、峰值；说话时配乐比人声低多少（目标 18~22 dB）、开头那一档高出多少、配乐在哪停下了；每个音效的起音落在哪一帧、和该落的那一帧差几帧（在音效分轨里实测，目标 0，超过 2 帧要查）。另出一张图：上面成片频谱，下面人声、配乐、音效三行音量，红线是画面事件开始，绿色是实测音效起音，蓝线是段落分界。结果写进交付说明。
